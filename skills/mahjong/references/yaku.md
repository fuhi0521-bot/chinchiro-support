# 役の全一覧

翻数は **門前 / 食い下がり後**。「門」は門前限定（鳴くと消える）。
複合の可否と、よくある誤解を各項に付けた。

## 1翻

| 役 | 翻 | 条件 | 注意 |
|---|---|---|---|
| **立直** | 1 | 門前テンパイで宣言、1000点供託 | 門 |
| **一発** | 1 | リーチ後1巡以内にアガリ（鳴きが入ると消える） | 門 |
| **門前清自摸和** | 1 | 門前でツモアガリ | 門 |
| **平和** | 1 | 4面子すべて順子・雀頭が役牌でない・**両面待ち** | 門。20符固定 |
| **断幺九** | 1 | 么九牌を1枚も使わない | 鳴いてもOK（喰いタン） |
| **一盃口** | 1 | 同じ順子が2組 | 門。鳴くと消える |
| **役牌（白/發/中）** | 1 | 三元牌の刻子・槓子 | 1種につき1翻 |
| **役牌（場風）** | 1 | 場風の刻子（東場なら東） | |
| **役牌（自風）** | 1 | 自風の刻子（南家なら南） | **連風牌は2翻** |
| **嶺上開花** | 1 | 槓の嶺上牌でツモアガリ | |
| **搶槓** | 1 | 他家の加槓の牌でロン | 暗槓は対象外 |
| **海底摸月** | 1 | 最後のツモ牌でアガリ | |
| **河底撈魚** | 1 | 最後の打牌でロン | |

### 平和の落とし穴

- **単騎・嵌張・辺張・双碰は平和にならない**。両面だけ。
- 雀頭が **自風・場風・三元牌** だと平和にならない。客風（自分に関係ない風）はOK。
- `13m` に `2m` は嵌張。`89m` に `7m` は辺張。`4567m` の `4m/7m` は**のべたん＝単騎扱い**なので平和なし。
- **平和ツモは20符**（ツモの+2符が付かない）。平和ロンは30符。

### 一盃口の落とし穴

- `112233m` は一盃口。`111222m` は一盃口ではない（順子2組と解釈できるが、
  対々和・三暗刻との比較で高い方を採る＝高点法）。
- 鳴いた瞬間に消える。ポンした後に `112233m` が残っていても付かない。

## 2翻

| 役 | 翻（門前/鳴き） | 条件 | 注意 |
|---|---|---|---|
| **ダブル立直** | 2 | 1巡目にリーチ（鳴きが入る前） | 門 |
| **七対子** | 2 | 異なる7種の対子 | 門。25符固定。同じ牌4枚は不可 |
| **三色同順** | 2 / 1 | 同じ数字の順子を3色 | |
| **一気通貫** | 2 / 1 | 同色で 123・456・789 | |
| **混全帯幺九（チャンタ）** | 2 / 1 | 全ての面子と雀頭に么九牌を含む・字牌あり | |
| **対々和** | 2 / 2 | 4面子すべて刻子・槓子 | |
| **三暗刻** | 2 / 2 | 暗刻が3つ | **ロンで完成した刻子は暗刻でない** |
| **三色同刻** | 2 / 2 | 同じ数字の刻子を3色 | 出現率は極めて低い |
| **三槓子** | 2 / 2 | 槓が3つ | |
| **混老頭** | 2 / 2 | 全ての牌が么九牌 | 対々和か七対子と必ず複合 |
| **小三元** | 2 / 2 | 三元牌が2刻子＋1対子 | 役牌2つと複合して**実質4翻** |

### 三暗刻の落とし穴

**ロンで完成した刻子は明刻扱い**。`111m` のうち最後の1枚をロンしたら、
その刻子は暗刻に数えない。ツモなら暗刻。四暗刻がロンで三暗刻+対々和に落ちるのはこれ。

### 混老頭の扱い

混老頭は必ず対々和（または七対子）と一緒になる。多くのルールで **チャンタは重ねない**
（混老頭が上位互換のため）。このエージェントの計算エンジンも重ねない。

## 3翻

| 役 | 翻（門前/鳴き） | 条件 |
|---|---|---|
| **二盃口** | 3 / — | 一盃口が2組。門前限定 |
| **純全帯幺九（純チャン）** | 3 / 2 | 全ての面子と雀頭に **1か9** を含む（字牌なし） |
| **混一色（ホンイツ）** | 3 / 2 | 1色 + 字牌 |

### 二盃口 vs 七対子

`112233445566m` + 雀頭 は二盃口（3翻）としても七対子（2翻）としても見えるが、
**七対子は「異なる7種」が条件**なので、同じ牌が4枚あるとそもそも成立しない。
`1122334455667m` 形は二盃口を採る。高点法で高い方が自動的に選ばれる。

## 役満

すべて **13翻相当**。複数成立すればダブル役満・トリプル役満になる。［ルール差］

| 役 | 条件 | 備考 |
|---|---|---|
| **国士無双** | 么九牌13種すべて＋どれか1枚 | 門。**十三面待ちはダブル**［ルール差］ |
| **四暗刻** | 暗刻4つ | 門。**単騎待ちはダブル**［ルール差］ |
| **大三元** | 白・發・中すべて刻子 | パオあり |
| **字一色** | 全て字牌 | |
| **緑一色** | `2s3s4s6s8s發` のみ | 發なしを条件にするルールもある |
| **清老頭** | 全て1と9 | |
| **小四喜** | 風牌3刻子＋1対子 | |
| **大四喜** | 風牌4刻子 | **ダブル**［ルール差］。パオあり |
| **四槓子** | 槓4つ | |
| **九蓮宝燈** | 同色で `1112345678999` ＋どれか1枚 | 門。**純正（九面待ち）はダブル**［ルール差］ |
| **天和** | 親が配牌でアガリ | |
| **地和** | 子が第1ツモでアガリ | 鳴きが入ると無効 |
| **人和** | 子が第1巡のロン | ［ルール差／雀魂は採用なし］ |

### 数え役満

役の翻数（ドラ含む）が **13翻以上** で役満扱い。［ルール差／雀魂はあり］
役満との複合はしない（13翻の数え役満 + 役満 は役満のまま）。

## 複合しない組み合わせ

覚えておくべき「重ならない」ペア。

- **平和 と 対々和 / 三暗刻 / 七対子** — 順子と刻子で排他
- **平和 と 単騎・嵌張・辺張・双碰** — 待ちの条件
- **七対子 と 二盃口** — 高点法でどちらか
- **混老頭 と チャンタ** — 混老頭が上位
- **チャンタ と 純チャン** — 純チャンが上位
- **混一色 と 清一色** — 清一色が上位
- **一盃口 と 二盃口** — 二盃口が上位
- **国士無双 と 他の役** — 単独

## 複合しやすい組み合わせ（狙う価値がある）

- **リーチ + ツモ + 平和 + 一盃口 + ドラ** — 門前の基本形。満貫が見える
- **混一色 + 役牌 + 対々和** — 鳴き手の主力。満貫級
- **小三元 + 役牌2つ** — 実質4翻、鳴いても跳満級
- **タンヤオ + 平和 + 三色 + ドラ** — 良形高打点の理想形
- **対々和 + 三暗刻** — 4翻。テンパイまで遠いので押し引きに注意

## 狙う価値のある役／ない役

| 役 | 狙うか | 理由 |
|---|---|---|
| タンヤオ・平和・役牌 | **常に見る** | 手なりで付く。受け入れをほぼ狭めない |
| ドラ・赤 | **常に見る** | 打点の主力。役ではないので役の確保を忘れない |
| 混一色 | **牌が寄っていれば** | 鳴けて打点が出る。ただし字牌が余ると遅い |
| 三色・一通 | **見えたら拾う** | 狙うと受け入れが狭くなる。手なり優先 |
| 七対子 | **対子4つ以上 + ドラ2以上** | それ以外は割に合わない |
| 対々和 | **暗刻2つ以上** | 対子3つからは遅い |
| チャンタ・純チャン | **ほぼ狙わない** | 受け入れが極端に狭い |
| 三暗刻・三槓子 | **狙わない** | できたら嬉しい程度 |
| 役満 | **狙わない** | 国士は么九牌が9種以上ある配牌のときだけ |

## エンジンで確認する

役の成立と翻数は暗算せず、必ず計算させる。

```bash
python3 skills/mahjong/scripts/mj.py score 234m567m234p678p11s --win 2m --tsumo --riichi
python3 skills/mahjong/scripts/mj.py score 555z666z77z123m456m --win 6z --fu-detail
```

複数の解釈がある形は **高点法**（いちばん高くなる解釈）で自動的に評価される。
