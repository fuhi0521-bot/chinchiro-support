# 迷いやすいルールの細部

実戦で年に数回しか出ないが、出たときに間違えると大きい。
［ルール差］は店・アプリで変わるところ。雀魂の段位戦の設定を基準にしてある。

## フリテン

**自分の待ち牌のどれか1枚でも自分の河にあれば、ロンできない。ツモはできる。**

| 状況 | ロン | ツモ |
|---|---|---|
| 待ち牌が自分の河にある | × | ○ |
| 三面待ちの1つだけ河にある | **× 全部の待ちで不可** | ○ |
| 他家の当たり牌を見逃した（同巡内） | × 次の自分のツモまで | ○ |
| 他家の当たり牌を見逃した（リーチ後） | **× その局ずっと** | ○ |
| 鳴きが入った | 同巡内フリテンは解除 | — |
| 待ちが変わって、新しい待ちは河にない | ○ | ○ |

**最大の事故は「リーチ後の待ち変わりフリテン」**。
リーチ前に、三面待ちの全ての牌が自分の河にないか必ず確認する。

## 役なしではアガれない

ドラ・赤ドラ・裏ドラは **役ではない**。ドラ4枚でも役がなければアガれない。

鳴いた手でこれをやると詰む。**鳴く前に「何の役でアガるか」を言えるようにする。**

形式テンパイは「役がないテンパイ」で、流局時の罰符のためだけに存在する。

## リーチ後にできること

| 行為 | 可否 |
|---|---|
| ツモ切り | ○（それしかできない） |
| ロン・ツモ | ○ |
| 暗槓 | △ **待ちと面子構成が変わらない場合のみ** |
| 明槓・ポン・チー | × |
| 手替え | × |
| 見逃し | ○ だが以後ロン不可 |

暗槓の条件は厳しい。`111m` を暗刻で使っている状態で4枚目を引いた場合はOK。
`1112m` のような形で待ちに関わっているならNG。

## 槓まわり

| 種類 | 新ドラ | 搶槓 | 備考 |
|---|---|---|---|
| 暗槓 | すぐめくれる | されない | 門前を崩さない。国士のみ搶槓可のルールもある ［ルール差］ |
| 加槓 | すぐめくれる | **される** | ポン済みに4枚目を足す |
| 大明槓 | すぐめくれる | されない | **ほぼ損**。新ドラを相手に乗せる |

- **槓ドラは全員に乗る**。自分の手が高くなる以上に、リーチ者が高くなる
- **リーチ者の裏ドラも増える**（槓ウラ）
- 槓が4つで **四開槓＝流局**。ただし1人で4つなら四槓子の目なので流局しない
- 嶺上牌を引くぶん、山が1枚減る

## 流局の種類

| 種類 | 条件 | 親 |
|---|---|---|
| 荒牌平局 | 山が尽きた | テンパイなら連荘 |
| 九種九牌 | 第1ツモ時点で么九牌9種類以上、本人の申告 | 連荘 ［ルール差］ |
| 四風連打 | 1巡目に4人が同じ風牌を切った | 連荘 |
| 四家立直 | 4人がリーチ | 連荘 |
| 四開槓 | 槓が4つ（2人以上） | 連荘 |
| 三家和 | 3人が同時にロン | 連荘 ［ルール差／頭ハネの店もある］ |

## ノーテン罰符

合計3000点。**形式テンパイでも受け取れる**。

| テンパイ者 | 1人あたり収入 | ノーテン1人あたり支払 |
|---|---|---|
| 1人 | +3000 | −1000 |
| 2人 | +1500 | −1500 |
| 3人 | +1000 | −3000 |
| 0人 / 4人 | 0 | 0 |

**テンパイとノーテンの差は最大4000点**（+3000 と −1000）。
1000点差・2000点差のオーラスでは、アガらなくても形式テンパイで着順が動く。

## 複数人がロンしたとき ［ルール差］

- **雀魂・多くのネット麻雀**: ダブロンあり。トリプルロンは流局
- **一部の店**: 頭ハネ（放銃者から見て上家に近い1人だけ）

ダブロンの場合:
- 放銃者は **両方に払う**
- **本場は両方に付く**（各300点）
- **リーチ棒（供託）は上家に近いほうが総取り**

## 責任払い（包・パオ） ［ルール差］

役満が確定する牌を鳴かせた人が支払いを被る。

| 役満 | 条件 | 雀魂 |
|---|---|---|
| 大三元 | 三元牌の3つ目を鳴かせた | あり |
| 大四喜 | 風牌の4つ目を鳴かせた | あり |
| 四槓子 | 4つ目の槓をさせた | なし |

- **ロンなら包の人が全額**
- **ツモなら包の人が全額**（折半のルールもある）

## 同点と着順

**同点の場合、起家に近いプレイヤーが上位。**
オーラスの条件計算でこれを忘れると1000点間違える。

席順は 起家（東1局の親）→ 南家 → 西家 → 北家 の順で上。

## 半荘の終わり方 ［ルール差］

雀魂の段位戦（四人半荘）:

1. **南4局が終わった時点で、誰かが30000点以上** → 終了
2. **誰も30000点に届かない** → **西入**（西1局へ）。西4局で強制終了
3. **誰かが0点未満** → 即終了（飛び）
4. **南場以降、親がトップかつ30000点以上でアガった** → 和了やめで終了できる

西入があるので「南4でトップなら安全」ではない。**30000点に届いているか**を見る。

## 喰い替え ［ルール差］

- **完全禁止**: `456m` を持っていて `4m` をチー → `4m` も `7m` も切れない
- **雀魂**: 現物喰い替え（同じ牌）のみ禁止。スジ喰い替え（`7m`）は **可**

## 後付け ［ルール差］

役が後から確定する形。
- **雀魂・ネット麻雀**: あり
- **完全先付けの店**: 禁止。鳴いた時点で役が確定していないといけない

リアルの相談では、**後付けの可否とトップ賞の有無を先に確認する**。
どちらも打ち方が変わる。
