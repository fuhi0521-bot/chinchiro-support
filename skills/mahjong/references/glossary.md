# 用語集

## 牌と手牌

| 用語 | 意味 |
|---|---|
| 数牌（シューパイ） | 萬子・筒子・索子。1〜9の数字牌 |
| 字牌（ツーパイ） | 風牌（東南西北）と三元牌（白發中） |
| 風牌（フォンパイ） | 東南西北 |
| 三元牌（サンゲンパイ） | 白發中。すべて役牌 |
| 役牌（ヤクハイ） | 三元牌 + 自風 + 場風。刻子にすると1翻 |
| 客風（オタカゼ） | 自分にも場にも関係ない風牌。役にならない |
| 連風牌（ダブ東など） | 自風と場風が一致する牌。刻子で2翻 |
| 么九牌（ヤオチューハイ） | 1・9・字牌 |
| 老頭牌（ロートーハイ） | 1と9のみ |
| 中張牌（チュンチャンパイ） | 2〜8 |
| ドラ | 表示牌の次の牌。1枚1翻ぶんの加算（役ではない） |
| 赤ドラ | 赤い5。1枚1翻 |
| 裏ドラ | リーチしてアガったときだけめくれるドラ |
| 王牌（ワンパイ） | 取れない14枚。ドラ表示牌と嶺上牌を含む |
| 嶺上牌（リンシャンパイ） | 槓したときに引く牌 |
| 海底（ハイテイ） | 最後のツモ牌 |
| 河底（ホウテイ） | 最後の打牌 |

## 形

| 用語 | 意味 |
|---|---|
| 面子（メンツ） | 完成した3枚組。順子か刻子 |
| 順子（シュンツ） | `456m` のような連続3枚 |
| 刻子（コーツ） | 同じ牌3枚 |
| 槓子（カンツ） | 同じ牌4枚 |
| 暗刻（アンコ） | 自分で揃えた刻子 |
| 明刻（ミンコ） | 鳴いた刻子、またはロンで完成した刻子 |
| 雀頭（ジャントウ） | 対子1組。「頭」とも |
| 対子（トイツ） | 同じ牌2枚 |
| 塔子（ターツ） | あと1枚で面子になる2枚組 |
| 両面（リャンメン） | `45m` → 3m6m。最強のターツ |
| 嵌張（カンチャン） | `35m` → 4m |
| 辺張（ペンチャン） | `12m` → 3m、`89m` → 7m |
| 双碰（シャンポン） | `44m 55m` → 4m5m |
| 単騎（タンキ） | 雀頭待ち |
| のべたん | `4567m` の 4m/7m 待ち。単騎扱い |
| 三面張（サンメンチャン） | `34567m` → 2m5m8m |
| 多門張（タモンチャン） | 3種類以上の待ち |
| 亜両面（アリャンメン） | `4456m` のような、両面に見えて選択がある形 |
| 中ぶくれ | `3455m` のような、内側が重なった形 |
| 孤立牌 | どのターツにも属していない牌 |
| ブロック | 面子・ターツ・雀頭の総称。和了には5つ必要 |

## 状態

| 用語 | 意味 |
|---|---|
| テンパイ | あと1枚でアガリ（シャンテン0） |
| ノーテン | テンパイしていない |
| シャンテン（向聴） | テンパイまであと何枚替える必要があるか |
| 一向聴（イーシャンテン） | あと1枚でテンパイ |
| 和了（ホーラ） | アガること。シャンテン −1 |
| 門前（メンゼン） | 鳴いていない状態。暗槓は門前を崩さない |
| 副露（フーロ） | 鳴くこと。ポン・チー・明槓 |
| 立直（リーチ） | 門前テンパイでの宣言。1000点供託 |
| ダマ（黙聴） | テンパイしているがリーチしない |
| 形式テンパイ | 役がないテンパイ。流局時の罰符のためだけ |
| フリテン | 自分の待ち牌が自分の河にある。ロン不可 |
| 一発（イッパツ） | リーチ後1巡以内のアガリ |
| 裏目 | 選ばなかったほうが正解だったこと |

## 進行

| 用語 | 意味 |
|---|---|
| 親（東家） | その局の起家。アガると連荘、打点1.5倍 |
| 子 | 親以外 |
| 上家（カミチャ） | 自分の左隣。この人からしかチーできない |
| 下家（シモチャ） | 自分の右隣 |
| 対面（トイメン） | 向かい |
| 連荘（レンチャン） | 親がアガるかテンパイで流局し、親が続くこと |
| 本場 | 連荘・流局の回数。1本につきロン+300、ツモ+100ずつ |
| 供託 | 場に出ているリーチ棒 |
| 流局 | 山が尽きて終わること |
| 荒牌平局 | 通常の流局 |
| 途中流局 | 九種九牌など、途中で終わる流局 |
| 半荘（ハンチャン） | 東場 + 南場。通常の1ゲーム |
| 東風戦 | 東場だけの短いゲーム |
| オーラス | 最終局（半荘なら南4局） |
| 飛び（ハコ） | 持ち点が0未満になって終了 |

## 戦術

| 用語 | 意味 |
|---|---|
| 押し引き | アガリに向かうか降りるかの判断 |
| ベタオリ | 完全に降りること。アガリを放棄する |
| 回し打ち | テンパイを維持しつつ安全な牌で進める |
| 現物（ゲンブツ） | その相手の河にある牌。ロンされない |
| 無筋（ムスジ） | スジになっていない牌 |
| スジ | `1m` が切れているときの `4m` など |
| 片スジ | 中張牌の片側だけがスジになっている状態 |
| ワンチャンス | 関連牌が3枚見えている |
| ノーチャンス | 関連牌が4枚見えていて両面で待てない |
| 壁（カベ） | 4枚見えている牌。ノーチャンスの根拠 |
| スジ引っかけ | スジを装った待ち。`4m` を切って `7m` 待ち |
| 河読み | 捨て牌から相手の手を推測すること |
| 手出し | 手牌から切ること（情報量が多い） |
| ツモ切り | 引いた牌をそのまま切ること |
| 5ブロック理論 | 和了に必要な5ブロックを軸に手を組む考え方 |
| 受け入れ | シャンテンが進む牌の種類と枚数 |
| 打点 | アガったときの点数 |
| 局収支 | その局だけの点数期待値 |
| 着順収支 | 順位ポイントを含めた期待値 |
| 素点 | 順位ポイントを除いた持ち点 |

## ツールと指標

| 用語 | 意味 |
|---|---|
| 牌譜 | 対局の記録。再生できる |
| Mortal | 無料のAI牌譜解析。打牌ごとのpt損失が出る |
| NAGA | 有料のAI牌譜解析。一致率と悪手率の推移 |
| MAKA | 雀魂公式の解析（無料枠あり） |
| 一致率 | AIの推奨打牌と一致した割合 |
| 悪手率 | 明確に損をした打牌の割合 |
| pt損失 | その打牌でどれだけ期待値を落としたか |
