### 玉の間の順位ポイント構造

**1着 +125 / 2着 +60 / 3着 −5 / 4着 大きなマイナス（段位が上がるほど重い）**

正確な4着の減点値と昇段に必要なptは**ゲーム内で確認する**（アップデートで変わる）。
判断に効くのは値そのものではなく **構造** で、次の2点だけ覚えていればいい。

1. **プラスは1着と2着だけ。3着はほぼゼロ。4着だけが大きく沈む**
2. だから **4着率を下げることが、1着率を上げることより効率がいい**（約1.6倍）

### 4着率の目安

**4着率20%を切っているか** が、雀聖到達のほぼ唯一の指標。
25%（完全均等）では段位ptは沈む。

| 4着率 | 評価 |
|---|---|
| 25%以上 | 押し引きに大きな穴がある |
| 22〜25% | 平均的。ここから伸ばす |
| 20〜22% | 雀豪上位 |
| 20%未満 | 雀聖到達圏 |

## UI に由来する注意点

### 手出し / ツモ切りが区別表示されない

雀魂の河は **手出しとツモ切りを見た目で区別しない**（リアルタイムで見ていれば分かる）。
これは読みの精度に直接効く。

対策: **「鳴いた直後の1打だけ覚える」** から始める。全部覚えようとすると破綻する。
鳴き後の1打は情報量が最も多い（何を残して何を捨てたかが分かる）。

### 自動和了・自動テンパイ設定

- **自動和了**をオンにしていると、見逃したい場面で勝手にアガる。
  オーラスの条件が絡む局では危険。段位戦では **オフ推奨**
- **自動ツモ切り**は思考時間を消費しないが、河の情報を相手に与えやすい

### 表示されるもの / されないもの

- **表示される**: 各自の点数、副露、河、ドラ表示牌、残り牌数、巡目
- **表示されない**: 手出し/ツモ切りの履歴、他家の手牌、山の中身
- **残り牌数**は必ず見る。終盤の押し引き判断に直結する

## 牌譜の見方

対局後に牌譜を再生できる。**相手の手牌が見える**ので、読みの答え合わせに使える。

- 牌譜URLは共有できるので、そのまま解析ツールに貼れる
- 「その時点で読めた情報」と「後から見えた情報」を必ず切り分ける

## リアル雀荘との差（判断が変わるところ）

| 項目 | 雀魂・段位戦 | リアル雀荘 |
|---|---|---|
| 評価 | 順位ポイント（ラス回避が最重要） | ウマ・オカ・**トップ賞** |
| 影響 | 3着と4着の差が最大 | 1着と2着の差が大きい |
| オーラスの方針 | 4着回避を優先 | トップを狙う価値が上がる |
| 切り上げ満貫 | なし | ありの店が多い |
| 後付け | あり | 完全先付けの店がある |
| 手出し/ツモ切り | 見えない | 見える |

**リアルの相談では、まずトップ賞の有無を確認する。** 結論が変わる。
