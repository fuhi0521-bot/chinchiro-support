# 押し引き

**成績差のほとんどはここで生まれる。** 牌効率より優先度が高い。

## 基準表（子・平場・7〜11巡目・子のリーチ1件）

| 自分の状態 | 打点 | 判断 |
|---|---|---|
| テンパイ・良形 | 満貫以上 | **押す** |
| テンパイ・良形 | 3900〜5200 | **押す** |
| テンパイ・良形 | 1000〜2600 | 押す（微差だが押し寄り） |
| テンパイ・悪形 | 満貫以上 | **押す** |
| テンパイ・悪形 | 3900〜5200 | 五分。現物があれば1枚は回る |
| テンパイ・悪形 | 安手 | **降りる** |
| 1シャンテン・両面2つ | 満貫級 | 押す |
| 1シャンテン・両面2つ | 安手 | 五分。回れるなら回る |
| 1シャンテン・良形1＋悪形1 | 満貫級 | 五分〜引き寄り |
| 1シャンテン・良形1＋悪形1 | 安手 | 降りる |
| 1シャンテン・悪形2つ | 問わず | **降りる** |
| 2シャンテン以下 | 問わず | **降りる** |

2シャンテン以下の例外は「序盤かつドラ暗刻級」くらい。それ以外は迷わず降りる。

## 補正条件

### 引く側に1段階寄せる

- **親リーチ** — 放銃打点が約1.5倍。子リーチより明確に引く
- **リーチが2件以上** — 危険度が単純に倍。テンパイ良形満貫でも慎重に
- **終盤（12巡目以降）** — 自分のアガリ率が落ちるので押す価値も落ちる
- **相手が明らかな高打点** — ドラポン、染め手、リーチ+一発+ドラ表示牌がその色
- **自分がトップ目で南場** — 放銃のダメージが着順に直結する

### 押す側に寄せる

- **序盤（1〜6巡目）のテンパイ** — 残り手数が多い。押し寄り
- **オーラスで着順条件を満たす手** — 局収支を無視してよい唯一の場面
- **ラス目でアガらないと着順が動かない** — 降りても失点は確定している
- **自分の待ちが強い** — 相手のリーチ宣言牌の近くを待っている、山に4枚残っている

### 変えなくていい

- **自分が親** — 親番の価値（連荘・打点1.5倍）と、放銃で親が流れるダメージがほぼ相殺。
  子のときと同じ基準でよい。

## 無筋の危険度（リーチ者1人に対する放銃率の目安）

```
無筋4〜6   ≈6.0%
無筋3・7   ≈5.0%
無筋2・8   ≈4.5%
無筋1・9   ≈4.0%
スジ       ≈3.0%
生牌の字牌  ≈3.0%（中盤以降）
ワンチャンス ≈2.5%
ノーチャンス ≈1.5%
現物        0%
```

場況で動くので **絶対値ではなく序列** として使う。
`mj.py danger --river "..." --tiles "..."` が同じ序列を機械的に出す。

### この序列に足りていないもの ［実測］

上の表は「牌の位置」と「スジ」しか見ていない。実測すると、
**同じ無筋でも「場に何枚切れているか」で危険度が半分以下になる**。

| 場に切れている枚数 | 数牌の当たり牌率 | 字牌 |
|---|---|---|
| 0枚（生牌） | 10.0% | 1.2% |
| 1枚 | 6.1% | 0.2% |
| 2枚 | 4.9% | 0.0% |
| 3枚 | **2.3%** | 0.0% |

（テンパイしている相手に対する値。上の表は「リーチ1件に対する放銃率」なので
テンパイ確率のぶん低く出ている。比べるのは**倍率**のほう）

**3枚切れの無筋はスジより安全。** 無筋を切らざるを得ないときは、
スジを探す前に **枚数の多い牌** を探す。

理由は2つ。シャンポン・単騎はその牌そのものを抱えている必要があること。
そしてより効くのが、**他家の河に切れている牌は、相手がテンパイしていたなら
通っている**（＝フリテンで和了れない）こと。

### リーチ後に通った牌は現物 ［厳密］

**リーチ宣言のあと、他家が切って誰もロンしなかった牌は、
そのリーチ者には二度と当たらない。** 見逃せば永久フリテンになるから。

確率ではなくルール上の帰結。リーチから5巡回れば、
本人の河に無くても10枚前後の完全安全牌ができている。**降りるときは必ず数える。**

### 序列が崩れる場面

- **染め手（ホンイツ）の相手** — 字牌がいちばん危険。スジは無意味
- **トイトイの相手** — 場に1枚も出ていない中張牌が危険。スジ関係なし
- **ダマの相手** — 危険度は測れない。副露と河の変化だけが手がかり
- **終盤の字牌** — 生牌の字牌は中盤以降は危険（単騎・シャンポンで待たれる）

## 回し打ち

「押すか降りるか」の中間。**テンパイを維持しつつ、通りやすい牌で進める**。

成立条件:
1. 現物か安全度の高い牌でも手が進む
2. 手が1シャンテン以上で、まだ形が決まっていない
3. 相手のリーチが1件だけ

**回し打ちは上級者の技**。中途半端にやると「押しても降りてもいない」最悪の状態になる。
迷ったら押すか降りるかに寄せる。

## ベタオリの手順

降りると決めた後の放銃がいちばんもったいない。順番を守る。

1. **現物** — 複数あるなら、他家にも通っている牌を温存する
2. **字牌** — 生牌より、誰かが1枚以上切っている字牌が安全
3. **スジ・ワンチャンス** — スジ引っかけがあるので過信しない
4. **壁（ノーチャンス）**
5. **無筋の1・9 → 2・8 → 3・7 → 4〜6** の順

### 降りる前に数える

「終局まであと何巡あるか」「安全牌は何枚あるか」。

残り8巡で安全牌が3枚しかないなら、**いま危険牌を1枚通しておく**ほうが安全なことがある。
終盤の一番危険な時間帯に無筋を切らされるより、いま比較的安全な無筋を切る。

### 複数リーチへの対応

- **両方に通る牌**（両者の現物）を最優先
- なければ **片方の現物 + もう片方のスジ**
- 全部無筋なら、**親リーチに通る牌**を優先する（打点が大きい）

## 押すときも安全牌を1枚残す

押すと決めても、**手の中の最後の安全牌を切ってはいけない**。
次巡に危険牌しか無くなると、降りたくなっても降りられない。

- 現物を2枚持っているなら、1枚は切っていい
- 1枚しかないなら、それは「保険」。同程度に危険な牌が他にあるならそちらを先に切る
- 保険を残すために受け入れを1〜2枚削るのは、たいてい割に合う

これは「押すか降りるか」を**今決めなくてよくする**技術。
リーチ相手に押し切るかどうかは、あと2巡見てから決めても遅くない。

## よくある失敗

1. **中途半端な押し引き** — 押すと決めたら押し切る、降りると決めたら降り切る。
   1枚押して危なくなって降りるのが期待値としては最悪。
2. **形式テンパイに寄りすぎる** — ノーテン罰符1000〜1500点のために
   満貫に放銃するのは割に合わない。**安全に取れるときだけ取る**。
3. **打点の過大評価** — 「リーチ・ツモ・裏で満貫」は、リーチしか確定していない
4. **スジの過信** — スジ引っかけ（`4m` が通ったから `7m` が安全、ではない）は普通にある
5. **1000点のリーチに全力で降りる** — 相手の打点も見る。安手なら押し返せる場面は多い
6. **副露を軽視する** — 3副露はリーチと同じ危険度。2副露も13巡目以降ならテンパイ扱い

## 判断が五分のとき

「五分」は立派な答え。無理にどちらかに決めると、実戦で判断がブレる。
ただし **五分と言い切る**こと。「状況次第です」で終わらせない。

五分の局面では次を優先する:
1. 自分の着順が悪い → 押す
2. 自分の着順が良い → 降りる
3. どちらでもない → 押す（アガリの価値は放銃の損失より少し大きいことが多い）
