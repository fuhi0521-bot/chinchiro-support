# 符計算と点数

## 結論から: ほとんどの手は暗記で足りる

実戦で符計算が要るのは **4翻以下** だけ。5翻以上は満貫以上で符が関係ない。
そして実際に出る組み合わせは限られている。

### ロンの点数（子 / 親）

| | 30符 | 40符 | 50符 | 60符 |
|---|---|---|---|---|
| **1翻** | 1000 / 1500 | 1300 / 2000 | 1600 / 2400 | 2000 / 2900 |
| **2翻** | 2000 / 2900 | 2600 / 3900 | 3200 / 4800 | 3900 / 5800 |
| **3翻** | 3900 / 5800 | 5200 / 7700 | 6400 / 9600 | 7700 / 11600 |
| **4翻** | 7700 / 11600 | 満貫 | 満貫 | 満貫 |

- **25符**（七対子）ロン: 2翻 1600/2400、3翻 3200/4800、4翻 6400/9600
- **20符**は平和ツモ専用なのでロンでは出ない（平和ロンは30符）

### ツモの支払い

「子が払う額 / 親が払う額」。親のツモは全員同額（オール）。

|---|---|---|
| **20符2翻**（平和ツモ） | 400 / 700 | 700オール |
| **20符3翻**（リーチ平和ツモ） | 700 / 1300 | 1300オール |
| **20符4翻** | 1300 / 2600 | 2600オール |

| **30符1翻** | 300 / 500 | 500オール |

### 満貫以上

|---|---|---|---|---|
| **満貫**（5翻） | 8000 | 2000/4000 | 12000 | 4000オール |

**切り上げ満貫**（4翻30符・3翻60符を満貫扱い）は雀魂の段位戦では **なし**。
7700 / 11600 のまま。［ルール差］

## 符計算の手順

### 1. 基本符 20符から始める

### 2. 加算する

| 要素 | 符 |
|---|---|
| 門前でロン | +10 |
| ツモ（平和を除く） | +2 |
| 中張牌の明刻 | +2 |
| 中張牌の暗刻 | +4 |
| 么九牌の明刻 | +4 |
| 么九牌の暗刻 | +8 |
| 中張牌の明槓 | +8 |
| 中張牌の暗槓 | +16 |
| 么九牌の明槓 | +16 |
| 么九牌の暗槓 | +32 |
| 役牌の雀頭（三元牌・自風・場風） | +2 |
| 単騎・嵌張・辺張待ち | +2 |
| 順子・両面待ち・双碰待ち | 0 |

### 3. 切り上げる

**1の位を切り上げて10の倍数にする**。22符 → 30符。

### 4. 例外

- **七対子は25符固定**（切り上げなし）
- **平和ツモは20符固定**（ツモの+2が付かない）
- **平和ロンは30符**（20 + 門前ロン10）
- **鳴いていて計算が20符になる場合は30符**（いわゆる喰いピン）

### 覚え方のコツ

- 刻子の符は **中張の明刻2符を基準に、暗刻で×2、么九で×2、槓で×4**
- 連風牌の雀頭は **2符**（雀魂・天鳳）。4符とするルールもある。［ルール差］
- **メンゼンロンの+10符を忘れる**のが最頻出ミス。30符と40符を取り違える。

## 計算例

### 例1: リーチのみ・両面ロン（子）

`234m 567m 234p 678p 11s` ロン `2m`
20（基本）+ 10（門前ロン）= 30符、リーチ1翻 → **30符1翻 = 1000点**

平和も付くので実際は 2翻30符 = 2000点。

### 例2: リーチ・ツモ・平和（子）

同じ手をツモ。平和ツモなので **20符3翻 = 700/1300（計2700点）**

### 例3: 役牌暗刻・嵌張ロン（子）

`123m 456p 789s 111z 22z` ロン `1z`（東場・南家）
20 + 10（門前ロン）+ 4（東を双碰でロン＝明刻・么九）= 34 → **40符**。
場風東1翻 + ドラ2 = 3翻40符 = **5200点**

### 例4: 小三元（子）

`555z 666z 77z 123m 456m` ロン `6z`
20 + 10 + 8（白の暗刻・字牌）+ 4（發をロンで明刻）+ 2（中の雀頭＝役牌）= 44 → **50符**。
白1 + 發1 + 小三元2 + 混一色3 = 7翻50符 = **跳満 12000点**

## 打点の見積り（実戦用）

局面判断では正確な点数より **段階** が分かればいい。

| 段階 | 目安 | 押し引きへの意味 |
|---|---|---|
| **安手** | 1000〜2600 | 悪形なら降り寄り |
| **中打点** | 3900〜5200 | 良形なら押す |
| **満貫級** | 7700〜8000 | 悪形でも押せる |
| **跳満以上** | 12000〜 | ほぼ押す |

「リーチ・ツモ・裏で満貫」は **リーチしか確定していない**。
確定している役と、確率的な上乗せ（ツモ・一発・裏・ドラ）を分けて考える。

確定分だけで満貫があるなら、それは「満貫の手」。
リーチ＋ドラ1で「満貫になるかも」は **3900の手**として扱う。
