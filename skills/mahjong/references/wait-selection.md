# 待ち取りと山読み

テンパイの形が複数選べるとき、どれを選ぶか。
牌効率が「テンパイまで」の話なら、これは「テンパイしてから」の話。
**アガリ率の差はここで一番大きく出る。**

## 待ちの基本序列

| 待ち | 最大枚数 | 平和 | 備考 |
|---|---|---|---|
| 三面張 | 12枚 | ○ | 最強 |
| 両面 | 8枚 | ○ | 標準 |
| 双碰（シャンポン） | 4枚 | × | 打点は上がりやすい |
| 嵌張（カンチャン） | 4枚 | × | |
| 辺張（ペンチャン） | 4枚 | × | 最弱 |
| 単騎 | 3枚 | × | 待ち替えが利く。字牌単騎は狙い目 |

**枚数だけで決めない。** 残っている枚数と、他家が持っていそうかで実質が変わる。

## 山読み — 残り枚数を数える

待ち牌が「4枚」でも、河に3枚出ていれば残り1枚。実質アガれない。

数えるもの:

1. **全員の河**
2. **全員の副露**
3. **ドラ表示牌**
4. **自分の手牌**

これを引いた残りが「山と他家の手牌にある枚数」。
`mj.py wait <手牌> --visible "<見えている牌>"` が自動で引いてくれる。

### 山読みの応用

- **早い巡目に切られている牌の周辺は山に残っている**。
  3巡目に `5s` が切られていれば、`4s6s` は他家に使われていない可能性が高い
- **リーチ者が切っている牌のスジは、自分の待ちとしても優秀**（他家も持っていない）
- **字牌は終盤まで残りやすい**。2枚見えの字牌単騎は残り2枚だが、
  他家が持っていれば出やすい（＝ロンできる）

**引き算した「残り枚数」がそのまま山にあるわけではない。**
残りは山と他家の手牌に分かれていて、その比率は牌の種類で大きく違う。
実測（見えていない1枚が実際に山にある確率）:

| 字牌 | 1・9 | 2・8 | 3・7 | 4・6 | 5 |
|---|---|---|---|---|---|
| 84.5% | 62.2% | 53.4% | 50.9% | 49.7% | 49.8% |

つまり **中張牌の「残り4枚」は実質2枚**。字牌はほぼ額面どおり山にある。
測り方と使い方は `wall-reading.md`。

### 「山に残っている」と「出やすい」は別

| 状況 | ツモりやすさ | ロンしやすさ |
|---|---|---|
| 中張牌の両面 | 高い | 中（危険牌なので止められる） |
| 字牌単騎 | 低い | 高い（安全牌として切られる） |
| 生牌の役牌単騎 | 低い | 低い（誰も切らない） |
| リーチ後の現物待ち | 中 | 非常に高い |

**ダマなら「出やすさ」、リーチなら「ツモりやすさ」を優先する。**
リーチすると他家が降りるので、出アガリの期待が下がる。

## 待ち取りの判断

同じシャンテンで複数のテンパイが取れるとき、この順で考える。

### 1. 枚数が明確に多いほうを取る

3枚差以上あれば、ほぼ枚数で決めていい。

### 2. 枚数が並んだら打点で決める

- **平和が付くか** — 両面なら付く。1翻＋ツモ時の20符
- **ドラを使えるか** — 待ちを変えてドラを組み込めるなら価値がある
- **役が確定するか** — タンヤオ・三色が確定するなら少し狭くてもよい

### 3. 打点も並んだら危険度で決める

- **切る牌が安全なほう** を選ぶ。同じテンパイなら放銃しないほうがいい
- 特に他家にリーチが入っている場面では、これが最優先になることもある

### 4. 待ち替えの余地を残す

単騎待ちは、ツモってきた牌で待ちを変えられる。
序盤の単騎テンパイは、良い待ちに変わる可能性を残して**ダマにする**選択がある。

## よく出る形の判断

### `4567m` + 雀頭 → 4m/7m ののべたん

- 6枚待ち。**平和は付かない**（単騎扱い）
- `456m + 7m単騎` と `567m + 4m単騎` の両方で見られる形
- 5m8m や 3m6m を引けば両面に変わる。待ち替えの余地が大きい

### `3455m` の中ぶくれ

- `345m + 5m` として、5m が雀頭候補になる優秀な形
- 5m を切って `345m` にするのはもったいない

### `44556m`

- `456m + 45m` → 3m6m 待ち（両面）
- `44m + 556m` → 4m雀頭のシャンポンや嵌張
- 枚数を数えれば前者が広い。だが打点（ドラ位置）で変わる

### 三面張を崩さない

`34567m` は 2m5m8m の12枚待ち。
これを `345m + 67m` と見て 5m を切ると 5m8m の8枚に減る。
**数えれば分かる。数えること。**

## テンパイしたら必ず確認する3つ

1. **フリテンでないか** — 三面待ちの1つでも自分の河にあれば全部ロンできない
2. **役があるか** — 門前ならリーチすれば解決。鳴いていたら要確認
3. **待ち牌が何枚残っているか** — 0枚なら待ち替えを考える

この3つを飛ばして「テンパったからリーチ」で事故る。

## エンジンで確認する

```bash
S=skills/mahjong/scripts/mj.py
python3 $S wait 34567m123p456p11s                        # 待ちと残り枚数
python3 $S wait 34567m123p456p11s --visible "2255m8m"    # 見えている牌を引く
python3 $S discard 3456778m234p55s99s --top 5            # テンパイ形の選択肢を比較
```

`--visible` に河とドラ表示牌を入れると、実質の残り枚数が出る。
「4枚待ち」が「実質1枚」になっていることは珍しくない。
