# 着順戦術とオーラス条件

## 東場・南場で判断軸が変わる

| 局面 | 見るもの |
|---|---|
| 東1〜東4 | **局収支**。素点を積む。着順はまだ動く |
| 南1〜南3 | 局収支と着順収支の中間。**ラス目かどうか**を意識し始める |
| 南4（オーラス） | **着順収支のみ**。素点は着順が動くときだけ意味を持つ |

東場でラス回避を意識しすぎると、単に手が縮むだけで逆効果。
**東場は普通に打つ。南場から着順を見る。**

## ラス回避が最優先である理由（雀魂・玉の間）

玉の間の順位ポイントは **1着 +125 / 2着 +60 / 3着 −5 / 4着 大きなマイナス**。
（4着の減点は段位が上がるほど重くなる。正確な値はゲーム内で確認する）

**4着の失点だけが段位とともに重くなる**ため、
**1着率を1%上げるより、4着率を1%下げるほうが約1.6倍効く**。

順位が完全に均等（各25%）でも段位ptは沈む。だから迷ったときの判断軸は
「アガれるか」ではなく **「この選択でラスる確率がどれだけ動くか」**。

リアル麻雀（トップ賞のある場）では話が変わる。その場合は先に確認する。

## オーラスの条件計算

エンジンで正確に出せる。暗算で間違えるところなので、必ず計算させる。

```bash
python3 skills/mahjong/scripts/mj.py oorasu --scores 24000,25000,25500,25500 --me 0 --dealer 3
```

```
席   点数    着順
0   24000   4着 ←自分
1   25000   3着
2   25500   1着
3   25500   2着  (親)

現在 4着（24000点）。3着 は席1（25000点、1000点差）
  ツモ: 1翻30符（300/500）以上
  直撃: 1000点以上
  他家からロン: 1000点以上

流局: 自分だけテンパイ → 1着 / 自分だけノーテン → 4着
```

`--sticks`（供託リーチ棒）と `--honba` も入る。**リーチ棒を出すと自分の点が
1000減るので、条件が変わる**。曲げる前に計算する。

### 手順

1. **現在の点差**を、自分と各対象者について出す
2. **順位が動く条件**を、ロン／ツモ／直撃で分けて出す
3. **供託とノーテン罰符**を入れる
4. 条件を満たす**最小の手**を決める（そこから逆算して打つ）

### 基本の関係

- **直撃（その相手からロン）** — 点差が **2倍** 縮まる。いちばん効率がいい
- **ツモ** — 相手から取るのは持ち点の一部だけ。必要打点が上がる
- **他家からのロン** — 自分の点数だけ増える。対象者の点は減らない

### よく出るパターン

| 状況 | 必要なもの |
|---|---|
| 1000点差で上に行きたい | **直撃なら1000点**（相手 −1000、自分 +1000 で 2000点差の移動） |
| 2000点差で上に行きたい | 直撃1000点 / 他家から2100点以上 / ツモ1000点（500/1000 なら 2000点差移動） |
| 4000点差で上に行きたい | 直撃2000点 / 他家から4100点以上 |
| 8000点差 | 直撃3900 / 他家から8100点（満貫） |
| 同点で上に行きたい | **上家取り**（席順で決まる）。起家に近いほうが上 |

**同点の場合、起家に近いプレイヤーが上位**。これを忘れて「同点なら並び」と
考えると条件を1000点間違える。

### ノーテン罰符を忘れない

流局時、自分がテンパイで相手がノーテンなら **最大4000点差** が動く（+3000 と −1000）。
1000点差・2000点差のオーラスでは、**アガらなくても形式テンパイで足りる**ことがある。

### 親のオーラス

- 親がアガると **連荘して局が続く**。トップなら和了やめ（雀魂の段位戦はあり）
- **ラス目の親** は連荘できるので、条件を満たすまで粘れる。
  ただし失点すると終わるので、押し引きは慎重に

## 点棒状況ごとの方針

### トップ目

- **放銃を避ける**。特に親リーチと満貫級への放銃
- 素点を積む価値は低い。**局を消化する**ほうが価値がある
- オーラスは全員に警戒。特に2着目の直撃条件を確認しておく

### 2着目

- トップとの点差次第。**捲れる差なら押す、無理なら3着に落ちない打ち方**
- 12000点差以上あるなら、無理に狙わず着順を守る

### 3着目

- **ラス目との点差がすべて**。1000点差ならアガリ1つで入れ替わる
- 逆に3着目からトップを狙って放銃してラスになるのが最悪のパターン
- 「4着に落ちる可能性」を常に計算に入れる

### ラス目

- **アガらないと着順が動かない**ので押す価値が高い
- ただし **満貫を放銃しても4着のまま** なら、放銃のダメージは小さい
- 局が残っているなら焦らない。オーラスまでに条件が縮まればいい
- 親番が残っているかを確認する。親の連荘は最大の武器

### ハコ下が近い（飛び終了がある場合）

- **飛ぶと即終了**。ラス回避どころではなくなる
- 残り点数が5000点を切ったら、放銃を避けることが最優先

## 局ごとの価値

| 局 | 特徴 |
|---|---|
| **東1** | 情報がない。手なりで打つ。無理をしない |
| **自分の親番** | 連荘の価値が高い。速度を1段上げてよい |
| **他家の親番** | 親を流す価値がある。安手でも速度で潰す |
| **南3** | オーラスの条件を作る局。ここでの着順が条件を決める |
| **オーラス** | 条件計算がすべて |

## 点数状況で打ち回しを変える

同じ手牌でも、点数状況で正解が変わる場面は限られている。**変えるべきところだけ変える。**

### リーチかダマか

| 状況 | 判断 | 理由 |
|---|---|---|
| オーラス・**トップ目** | **ダマ** | アガれば終局。打点は要らない。リーチ棒1000点を出すと捲られる条件が変わる |
| オーラス・ダマで条件を満たす | **ダマ** | リーチすると他家が降りて、出アガリの機会が減る |
| オーラス・ダマでは足りない | **リーチ** | 一発・裏で条件に届く可能性を買う |
| オーラス・すでに条件を満たしている | **ダマ**（形式テンパイで足りる） | 放銃だけ避ければいい |
| 南場・大きくリードしている（12000点差以上） | **ダマ寄り** | 押し込む必要がない |
| それ以外 | **リーチ** | 原則は先制リーチ |

### 見逃し（アガらない選択）

**オーラスでラス目のときだけ**、着順が上がらない和了を見逃す価値がある。
アガると半荘が終わってラスが確定するため。

見逃してはいけない場面:

- **ラス目以外** — 見逃すと逆に落ちる危険がある。必ずアガる
- **自分が親** — アガれば連荘。次の機会が来るので必ずアガる
- **残り4巡を切っている** — 次の機会がもう無い
- **見逃すとフリテンになる** — その局はもうロンできない。これが見逃しの本当のコスト

### 形式テンパイ

オーラスの終盤（13巡目以降）、**上下の相手との点差が4000点以内**なら、
テンパイかノーテンかで着順が動く（テンパイで+3000、ノーテンで−1000、最大4000点差）。
このときだけ形式テンパイを取りに行く価値がある。

それ以外の局面では、**ノーテン罰符1000〜1500点のために満貫に放銃するのは割に合わない**。

### 押し引き

| 状況 | 補正 |
|---|---|
| ラス目 | 押し寄り。降りても失点は確定している |
| 3着目 | やや押し寄り。ただしラス落ちを常に計算に入れる |
| トップ目・オーラス | 引き。放銃だけを避ければ勝ち |
| トップ目・南場（オーラス以外） | **変えすぎない**（後述） |

## 「トップ目だから守る」は効いているのか

1000半荘のシミュレーションで検証した結果、**「トップ目のとき慎重になる」補正は
和了率を落とすだけで、順位はむしろ悪化した**（`results/` を参照）。

理由は単純で、守っても点棒は増えず、他家のアガリで削られ続けるから。
守りが効くのは **オーラスのトップ目**（アガれば終局が確定する）だけで、
南場に入っただけで守りに回るのは早すぎる。

一方、**「下位のとき押す」補正は効く**。これは「降りても失点が確定している」
という構造から来ていて、ラス回避と矛盾しない。

## 判断に迷ったときの序列（南場）

1. **4着に落ちない**
2. **3着以上を維持する**
3. **着順を1つ上げる**
4. 素点を積む

この順序が逆転するのは、**リアルのトップ賞がある場**と、
**オーラスで既に条件を満たしている場合**だけ。
