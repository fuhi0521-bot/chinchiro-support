# 着順戦術とオーラス条件

## 東場・南場で判断軸が変わる

| 局面 | 見るもの |
|---|---|
| 東1〜東4 | **局収支**。素点を積む。着順はまだ動く |
| 南1〜南3 | 局収支と着順収支の中間。**ラス目かどうか**を意識し始める |
| 南4（オーラス） | **着順収支のみ**。素点は着順が動くときだけ意味を持つ |

東場でラス回避を意識しすぎると、単に手が縮むだけで逆効果。
**東場は普通に打つ。南場から着順を見る。**

## ラス回避が最優先である理由（雀魂・玉の間）

玉の間の順位ポイントは **1着 +125 / 2着 +60 / 3着 −5 / 4着 大きなマイナス**。
（4着の減点は段位が上がるほど重くなる。正確な値はゲーム内で確認する）

**4着の失点だけが段位とともに重くなる**ため、
**1着率を1%上げるより、4着率を1%下げるほうが約1.6倍効く**。

順位が完全に均等（各25%）でも段位ptは沈む。だから迷ったときの判断軸は
「アガれるか」ではなく **「この選択でラスる確率がどれだけ動くか」**。

リアル麻雀（トップ賞のある場）では話が変わる。その場合は先に確認する。

## オーラスの条件計算

### 手順

1. **現在の点差**を、自分と各対象者について出す
2. **順位が動く条件**を、ロン／ツモ／直撃で分けて出す
3. **供託とノーテン罰符**を入れる
4. 条件を満たす**最小の手**を決める（そこから逆算して打つ）

### 基本の関係

- **直撃（その相手からロン）** — 点差が **2倍** 縮まる。いちばん効率がいい
- **ツモ** — 相手から取るのは持ち点の一部だけ。必要打点が上がる
- **他家からのロン** — 自分の点数だけ増える。対象者の点は減らない

### よく出るパターン

| 状況 | 必要なもの |
|---|---|
| 1000点差で上に行きたい | **直撃なら1000点**（相手 −1000、自分 +1000 で 2000点差の移動） |
| 2000点差で上に行きたい | 直撃1000点 / 他家から2100点以上 / ツモ1000点（500/1000 なら 2000点差移動） |
| 4000点差で上に行きたい | 直撃2000点 / 他家から4100点以上 |
| 8000点差 | 直撃3900 / 他家から8100点（満貫） |
| 同点で上に行きたい | **上家取り**（席順で決まる）。起家に近いほうが上 |

**同点の場合、起家に近いプレイヤーが上位**。これを忘れて「同点なら並び」と
考えると条件を1000点間違える。

### ノーテン罰符を忘れない

流局時、自分がテンパイで相手がノーテンなら **最大4000点差** が動く（+3000 と −1000）。
1000点差・2000点差のオーラスでは、**アガらなくても形式テンパイで足りる**ことがある。

### 親のオーラス

- 親がアガると **連荘して局が続く**。トップなら和了やめ（雀魂の段位戦はあり）
- **ラス目の親** は連荘できるので、条件を満たすまで粘れる。
  ただし失点すると終わるので、押し引きは慎重に

## 点棒状況ごとの方針

### トップ目

- **放銃を避ける**。特に親リーチと満貫級への放銃
- 素点を積む価値は低い。**局を消化する**ほうが価値がある
- オーラスは全員に警戒。特に2着目の直撃条件を確認しておく

### 2着目

- トップとの点差次第。**捲れる差なら押す、無理なら3着に落ちない打ち方**
- 12000点差以上あるなら、無理に狙わず着順を守る

### 3着目

- **ラス目との点差がすべて**。1000点差ならアガリ1つで入れ替わる
- 逆に3着目からトップを狙って放銃してラスになるのが最悪のパターン
- 「4着に落ちる可能性」を常に計算に入れる

### ラス目

- **アガらないと着順が動かない**ので押す価値が高い
- ただし **満貫を放銃しても4着のまま** なら、放銃のダメージは小さい
- 局が残っているなら焦らない。オーラスまでに条件が縮まればいい
- 親番が残っているかを確認する。親の連荘は最大の武器

### ハコ下が近い（飛び終了がある場合）

- **飛ぶと即終了**。ラス回避どころではなくなる
- 残り点数が5000点を切ったら、放銃を避けることが最優先

## 局ごとの価値

| 局 | 特徴 |
|---|---|
| **東1** | 情報がない。手なりで打つ。無理をしない |
| **自分の親番** | 連荘の価値が高い。速度を1段上げてよい |
| **他家の親番** | 親を流す価値がある。安手でも速度で潰す |
| **南3** | オーラスの条件を作る局。ここでの着順が条件を決める |
| **オーラス** | 条件計算がすべて |

## 判断に迷ったときの序列（南場）

1. **4着に落ちない**
2. **3着以上を維持する**
3. **着順を1つ上げる**
4. 素点を積む

この順序が逆転するのは、**リアルのトップ賞がある場**と、
**オーラスで既に条件を満たしている場合**だけ。
