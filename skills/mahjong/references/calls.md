# 鳴き判断

判断軸は「アガリが近づくか」ではなく **「鳴いた後の手がどうなるか」**。
鳴きは speed を買って、**打点・守備力・柔軟性を売る**取引。

## 鳴いてよい3条件（すべて満たすなら鳴く）

1. **役が確定している** — 役牌・タンヤオ・染め手・トイトイの目処
2. **打点が1500以上ある、または局面が速度勝負** — 親番／オーラス条件／ラス目
3. **鳴いた後も安全牌と手牌の柔軟性が残る**

3つ目を忘れて「鳴いたら降りられなくなった」が最頻出の事故。

### 打点の線は 3900 ではなく 1500 だった ［実測］

ここには長く「3900以上」と書いてあったが、一度も測っていなかった。
混成卓（2対2、席を入れ替えて各6000席局）で直接ぶつけると、

| 最低打点 | 和了率 | 放銃率 | 素点/局 |
|---|---|---|---|
| **1500** | **19.7%** | 10.1% | **+232.5** |
| 3900 | 17.8% | 10.2% | +162.5 |

**和了率 +1.90pt（標準誤差0.5pt）に対して、放銃率は変わらない。**

打点で門を上げると放銃まで増える理由は、テンパイ到達率で見える。
3900 にすると **67.0% → 60.7%** に落ちた。テンパイできないまま
他家のテンパイを受ける局が増えるので、速度だけでなく守備も悪くなる。

「鳴きは打点を売って速度を買う」は正しいが、
**売った打点が守備力まで道連れにする**ことが抜けていた。

同じ測定で「何シャンテンまで鳴くか」も、2 より **3** が良かった
（和了 +1.13pt / 放銃 −0.43pt）。遠くても鳴いてよい。

注意: これはシミュレータの打ち手集団に対する測定で、人間の卓の話ではない。
1000 と 1500 の差は無かった（根拠は弱い）。

## 鳴きの価値が高い場面

- **役牌の1鳴き** — 役が確定し、手が2〜3巡早くなる。ドラが絡めば即鳴き
- **ドラが3枚以上ある** — 打点が足りているので速度に変えてよい
- **染め手が見えている** — ホンイツは鳴いても2翻。役牌が絡めば満貫級
- **自分が親** — 連荘の価値が高い。安手でも速度を取る場面がある
- **オーラスで着順条件がある** — 1000点でも着順が動くなら鳴く
- **他家が明らかに高い手を進めている** — 速度で潰す

## 鳴いてはいけない形

| 形 | 理由 |
|---|---|
| **役なしになる** | タンヤオも役牌もない鳴きは、テンパイしてもアガれない |
| **1000点で愚形残り** | 速くもなく高くもない。降りる手段も失う |
| **789 のチーで平和・三色が消える** | 門前の打点を捨てて速度が大して上がらない |
| **雀頭がないのに鳴く** | 頭なしテンパイは待ちが単騎に固定されやすい |
| **安全牌が1枚もない状態での鳴き** | 直後に危険牌を切らされる |
| **2シャンテン以上からの安手の鳴き** | ~~まだ遠い~~ → **実測では逆**。下の注を読む |

**注（実測）**: 「遠いから鳴かない」は測ると損だった。
何シャンテンまで鳴くかを 1 / 2 / 3 で振ると、**3（遠くても鳴く）が最良**。

| 許容シャンテン | 和了率 | 放銃率 | 局あたり和了 | 流局 |
|---|---|---|---|---|
| 1 | 30.6%※ | 12.2% | 0.706 | 149 |
| 2 | 24.4% | 8.7% | 0.772 | 115 |
| **3** | 24.4% | **8.6%** | 0.756 | 124 |

※ `1` の高い和了率は**選択の偏り**。ほぼ完成した手しか鳴かないので
鳴いた局の成績は良く見えるが、局全体では和了が最も少なく流局が最も多い。
**「鳴いた手の勝率」で鳴きの基準を決めてはいけない**、の実例。

混成卓では 3 が 2 に 和了 +1.13pt / 放銃 −0.43pt で勝った。

残る条件（役が確定するか・安全牌が残るか）のほうが、遠さより大事。

## 具体的な判断

### 役牌のポン

| 状況 | 判断 |
|---|---|
| ドラ2以上 or 赤あり | **即鳴き** |
| ドラなし・手が4シャンテン以上 | 鳴かない（さすがに遠い） |
| ドラなし・3シャンテンまで | **鳴く**（実測で遠い鳴きは損ではない） |
| 自分が親 | 基準を1段緩める |
| オーラスで条件を満たす | 鳴く |
| 2枚目の役牌（1枚目をスルー済み） | 原則鳴く。スルーの理由が消えていなければ再考 |

### 孤立した役牌を「鳴くために」持つ価値 ［実測］

1枚の役牌を抱えるのは、重ねてポンするため。その重なる確率は牌山だけで決まる。

| 自分のツモ | 2枚目が来る |
|---|---|
| 6巡 | 14.2% |
| 9巡 | 20.7% |
| 12巡 | **26.9%** |
| 17巡（最後まで） | 36.5% |

他家が1枚切っても、**1枚では鳴けない**ので関係ない。
道は「自分でツモって重ねる」だけ。

**12巡持って4回に1回。** これに見合うのは、その1枚が
**6ブロック目の種として要るとき**だけ。5ブロックそろっているなら、
期待値27%の種のために毎巡1枚ぶん手を狭めていることになる。

→ 切る判断は巡目ではなく **ブロック数** で決める（`efficiency.md` 参照）

### タンヤオのチー

- **鳴いた後にタンヤオが確定するか**を必ず確認する。么九牌が手に残っていたら不成立
- ドラ・赤が絡んでいれば積極的に。ドラなしタンヤオのみ（1000点）でも、
  **テンパイが近いなら鳴いてよい**（打点の門は測ると1500で十分だった）
- **789 や 123 のチーはタンヤオを壊す**。何のために鳴くのかを言えないなら鳴かない

### 染め手（ホンイツ・チンイツ）

- **6巡目までに、その色 + 字牌が9枚以上** なら現実的
- 役牌が絡めば満貫級。絡まないホンイツは3900〜5200
- **バレやすい**（河の色でモロバレ）ので、テンパイまで行かないと苦しい
- チンイツは鳴いても5翻。ただし字牌の安全牌が持てないので守備が壊滅する

### トイトイ

- **対子3つ以上 + ドラ絡み** が最低条件
- 対子だけでは遅い。暗刻が1つあると現実味が出る
- 鳴くと三暗刻・四暗刻が消える。**暗刻2つあるなら門前で粘る価値**がある

### カン

カンは **リスクの高い行為**。新ドラが全員に乗る。

| 状況 | 判断 |
|---|---|
| 暗槓・自分がテンパイ・打点が欲しい | **する** |
| 暗槓・待ちと面子構成が変わらない・リーチ後 | する（リーチ後の暗槓は条件付きで可） |
| 明槓（大明槓）・テンパイでない | **しない**。新ドラを相手に乗せるだけ |
| 加槓・相手にリーチ者がいる | **しない**。搶槓と新ドラのリスク |
| 自分がラス目で打点が要る | 一考。ただし他家に乗るリスクを飲む |

**大明槓はほぼ損**。テンパイが確定して打点も上がるとき以外はやらない。

## 喰い替えと後付け ［ルール差］

- **喰い替え禁止**: `456m` を持っていて `4m` をチーして `4m` を切る、は不可。
  雀魂は「現物喰い替え」（同じ牌）のみ禁止で、`7m` 切り（スジ喰い替え）は可。
- **後付け**: 役が後から確定する形。雀魂・一般的なネット麻雀では **あり**。
  リアルの店では「完全先付け」で禁止のことがあるので、リアルの相談では確認する。

## 鳴いた後の打ち方

鳴いた瞬間から **守備力が落ちている**ことを自覚する。

1. **安全牌を1枚は抱える**（特に字牌）
2. **テンパイまでの巡数を数える** — 残り巡数で間に合わないなら鳴かない判断もあった
3. **他家のリーチが入ったら即座に押し引き判断** — 鳴いた手は降りにくい。
   降りると決めたら手を壊してでも降りる

## よくある間違い

1. **役の確認忘れ** — 鳴いてから「アガれない」に気づく。最悪の事故
2. ~~**1000点を鳴く**~~ — **実測では 1000 と 1500 に差が無かった**。
   問題は打点ではなく「役が確定していない鳴き」と「安全牌を失う鳴き」のほう
3. **鳴いた後に安全牌がない** — 鳴く前に手の中を見る
4. **とりあえずポン** — 鳴く目的（役・打点・速度・着順）を言えないなら鳴かない
5. **大明槓** — 新ドラのリスクに見合わないことがほとんど
