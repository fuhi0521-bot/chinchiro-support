# 鳴き判断

判断軸は「アガリが近づくか」ではなく **「鳴いた後の手がどうなるか」**。
鳴きは speed を買って、**打点・守備力・柔軟性を売る**取引。

## 鳴いてよい3条件（すべて満たすなら鳴く）

1. **役が確定している** — 役牌・タンヤオ・染め手・トイトイの目処
2. **打点が3900以上ある、または局面が速度勝負** — 親番／オーラス条件／ラス目
3. **鳴いた後も安全牌と手牌の柔軟性が残る**

3つ目を忘れて「鳴いたら降りられなくなった」が最頻出の事故。

## 鳴きの価値が高い場面

- **役牌の1鳴き** — 役が確定し、手が2〜3巡早くなる。ドラが絡めば即鳴き
- **ドラが3枚以上ある** — 打点が足りているので速度に変えてよい
- **染め手が見えている** — ホンイツは鳴いても2翻。役牌が絡めば満貫級
- **自分が親** — 連荘の価値が高い。安手でも速度を取る場面がある
- **オーラスで着順条件がある** — 1000点でも着順が動くなら鳴く
- **他家が明らかに高い手を進めている** — 速度で潰す

## 鳴いてはいけない形

| 形 | 理由 |
|---|---|
| **役なしになる** | タンヤオも役牌もない鳴きは、テンパイしてもアガれない |
| **1000点で愚形残り** | 速くもなく高くもない。降りる手段も失う |
| **789 のチーで平和・三色が消える** | 門前の打点を捨てて速度が大して上がらない |
| **雀頭がないのに鳴く** | 頭なしテンパイは待ちが単騎に固定されやすい |
| **安全牌が1枚もない状態での鳴き** | 直後に危険牌を切らされる |
| **2シャンテン以上からの安手の鳴き** | まだ遠い。門前で打点を作る余地を残す |

## 具体的な判断

### 役牌のポン

| 状況 | 判断 |
|---|---|
| ドラ2以上 or 赤あり | **即鳴き** |
| ドラなし・手が3シャンテン以上 | 鳴かない（1000点になる） |
| ドラなし・1シャンテン | 鳴く（テンパイ即入り） |
| 自分が親 | 基準を1段緩める |
| オーラスで条件を満たす | 鳴く |
| 2枚目の役牌（1枚目をスルー済み） | 原則鳴く。スルーの理由が消えていなければ再考 |

### タンヤオのチー

- **鳴いた後にタンヤオが確定するか**を必ず確認する。么九牌が手に残っていたら不成立
- ドラ・赤が絡んでいれば積極的に。ドラなしタンヤオのみ（1000点）は基本スルー
- **789 や 123 のチーはタンヤオを壊す**。何のために鳴くのかを言えないなら鳴かない

### 染め手（ホンイツ・チンイツ）

- **6巡目までに、その色 + 字牌が9枚以上** なら現実的
- 役牌が絡めば満貫級。絡まないホンイツは3900〜5200
- **バレやすい**（河の色でモロバレ）ので、テンパイまで行かないと苦しい
- チンイツは鳴いても5翻。ただし字牌の安全牌が持てないので守備が壊滅する

### トイトイ

- **対子3つ以上 + ドラ絡み** が最低条件
- 対子だけでは遅い。暗刻が1つあると現実味が出る
- 鳴くと三暗刻・四暗刻が消える。**暗刻2つあるなら門前で粘る価値**がある

### カン

カンは **リスクの高い行為**。新ドラが全員に乗る。

| 状況 | 判断 |
|---|---|
| 暗槓・自分がテンパイ・打点が欲しい | **する** |
| 暗槓・待ちと面子構成が変わらない・リーチ後 | する（リーチ後の暗槓は条件付きで可） |
| 明槓（大明槓）・テンパイでない | **しない**。新ドラを相手に乗せるだけ |
| 加槓・相手にリーチ者がいる | **しない**。搶槓と新ドラのリスク |
| 自分がラス目で打点が要る | 一考。ただし他家に乗るリスクを飲む |

**大明槓はほぼ損**。テンパイが確定して打点も上がるとき以外はやらない。

## 喰い替えと後付け ［ルール差］

- **喰い替え禁止**: `456m` を持っていて `4m` をチーして `4m` を切る、は不可。
  雀魂は「現物喰い替え」（同じ牌）のみ禁止で、`7m` 切り（スジ喰い替え）は可。
- **後付け**: 役が後から確定する形。雀魂・一般的なネット麻雀では **あり**。
  リアルの店では「完全先付け」で禁止のことがあるので、リアルの相談では確認する。

## 鳴いた後の打ち方

鳴いた瞬間から **守備力が落ちている**ことを自覚する。

1. **安全牌を1枚は抱える**（特に字牌）
2. **テンパイまでの巡数を数える** — 残り巡数で間に合わないなら鳴かない判断もあった
3. **他家のリーチが入ったら即座に押し引き判断** — 鳴いた手は降りにくい。
   降りると決めたら手を壊してでも降りる

## よくある間違い

1. **役の確認忘れ** — 鳴いてから「アガれない」に気づく。最悪の事故
2. **1000点を鳴く** — 速度も打点もない。守備だけ失う
3. **鳴いた後に安全牌がない** — 鳴く前に手の中を見る
4. **とりあえずポン** — 鳴く目的（役・打点・速度・着順）を言えないなら鳴かない
5. **大明槓** — 新ドラのリスクに見合わないことがほとんど
