# ルールと進行

日本リーチ麻雀（四人半荘・東南戦）の標準ルール。雀魂の既定設定に合わせてある。
ルール差が結論を変えるところには **［ルール差］** を付けた。

## 卓と牌

- 牌は **136枚**。数牌 3種 × 9 × 4枚 = 108、字牌 7種 × 4枚 = 28。
- 数牌: 萬子 `1m-9m` / 筒子 `1p-9p` / 索子 `1s-9s`
- 字牌: 風牌 `東 南 西 北` / 三元牌 `白 發 中`
- **么九牌** = 1と9と字牌。**中張牌** = 2〜8。**老頭牌** = 1と9のみ。
- 赤ドラは `5m/5p/5s` を赤牌に差し替えたもの。雀魂は **各1枚・計3枚**。［ルール差］

## 半荘の進行

1. 東1局から始まり、親が右回りに移る。東4局が終わると南場へ。
2. **南4局（オーラス）が終わると半荘終了**。ただし親がアガるか親がテンパイで流局すると
   **連荘**して局が続く（東4局・南4局でも同じ。南入・西入の条件はルール差）。
3. 持ち点 25000点スタート、30000点返し。［ルール差］
4. 誰かが **0点未満（ハコ下）** になった時点で終了（飛び）。［ルール差／雀魂はあり］

### 1局の流れ

配牌13枚 → 親からツモ・打牌 → 誰かがアガるか、山が尽きて流局。
王牌14枚は取らない（ドラ表示牌＋嶺上牌）ので、ツモれるのは **各自最大18回**。
「17巡目まで」が実質の終わり。

### 本場と供託

- 親の連荘・流局のたびに **本場** が1つ増える。
- 本場1つにつき、ロンなら和了者に **+300点**（放銃者が払う）、
  ツモなら **各家+100点ずつ**。
- リーチ棒（1000点）は場に残り、**次のアガリ者が総取り**。流局時は持ち越し。

## 副露（鳴き）

| 種類 | 対象 | 誰から | 備考 |
|---|---|---|---|
| **ポン** | 同じ牌3枚 | 誰からでも | チーより優先 |
| **チー** | 連続する数牌3枚 | 上家のみ | |
| **大明槓** | 同じ牌4枚 | 誰からでも | 嶺上牌をツモり、新ドラが即めくれる |
| **加槓（小明槓）** | ポン済みに4枚目 | — | **搶槓** の対象になる |
| **暗槓** | 自分で4枚 | — | **門前を崩さない**。新ドラが即めくれる |
| **ロン** | アガリ牌 | 誰からでも | |

- 鳴くと **門前が崩れる**（暗槓を除く）。リーチ・ツモ・平和・一盃口・七対子などが消える。
- **喰い替えは禁止**。［ルール差／雀魂は現物喰い替えのみ禁止］
- **鳴いた直後は打牌が必要**。安全牌を持っていないと危険牌を切らされる。

## リーチ

条件: **門前**、**テンパイ**、**点数1000点以上**、**山に4枚以上残っている**（＝流局まで打牌が可能）。

- 宣言後は **手牌を変えられない**（ツモ切りのみ。ただしアガリと暗槓は可能。
  暗槓は待ちと面子構成が変わらない場合のみ）。
- **一発**: リーチ後、次の自分のツモまでに鳴きが入らずアガれば1翻。
- **裏ドラ**: リーチしてアガった場合のみ、裏ドラ表示牌がめくれる。
- リーチ後に **フリテン** になったら、その局はロンできない（ツモは可）。

## フリテン

**自分の待ち牌のどれか1枚でも自分の河にあれば、ロンできない**（ツモはできる）。

- 三面待ちのうち1つでも河にあれば、**全ての待ちでロン不可**。ここが一番の事故ポイント。
- **同巡内フリテン**: 見逃した直後は次のツモまでロンできない（鳴きが入るとリセット）。
- **リーチ後の見逃し**: その局はずっとロン不可（リーチ後フリテン）。

## 流局

### 通常流局（荒牌平局）

山が尽きたら、テンパイ者とノーテン者で **ノーテン罰符** をやり取りする（合計3000点）。

| テンパイ者 | テンパイ1人あたり | ノーテン1人あたり |
|---|---|---|
| 1人 | +3000 | -1000 |
| 2人 | +1500 | -1500 |
| 3人 | +1000 | -3000 |
| 0人 / 4人 | 0 | 0 |

- **形式テンパイ**（役なしでもよい）で罰符は受け取れる。
- 親がテンパイなら **連荘**。ノーテンなら親が流れる。

### 途中流局 ［ルール差／雀魂は全てあり］

| 名前 | 条件 |
|---|---|
| **九種九牌** | 第1ツモ時点で么九牌が9種類以上。本人の申告で流局 |
| **四風連打** | 1巡目に4人が同じ風牌を切った |
| **四家立直** | 4人がリーチした（4人目のリーチが通った時点） |
| **四開槓** | 槓が4つ（1人で4つなら流局しない＝四槓子の目） |
| **三家和** | 3人が同時にロン。［ルール差／雀魂は流局］ |

### 流し満貫 ［ルール差］

流局時、自分の河が **么九牌だけ**で、かつ1枚も鳴かれていなければ満貫扱い。
雀魂ではあり（親は12000、子は8000相当）。

## アガリの優先順位

- 複数人がロンした場合、**ダブロンあり**（雀魂）。トリプルロンは流局。［ルール差］
  頭ハネ（上家優先）のルールもある。
- **ロンとツモが同時**にはならない（打牌に対するロンが先）。

## 役なしではアガれない

**1翻以上の役が必要**。ドラ・赤ドラ・裏ドラは役ではないので、
ドラ4枚あっても役がなければアガれない。これが形式テンパイの正体。

## 責任払い（包・パオ） ［ルール差］

- **大三元**: 三元牌3つ目を鳴かせた人が、ロンなら全額、ツモなら全額を払う。
- **大四喜**: 風牌4つ目を鳴かせた人が同様。
- 雀魂は大三元・大四喜のパオあり。四槓子のパオは無し。

## 雀魂とリアル雀荘のおもな差

| 項目 | 雀魂（段位戦） | 一般的なリアル雀荘 |
|---|---|---|
| 赤ドラ | 各1枚（計3枚） | 各1枚が多い。0枚や各2枚も |
| 喰いタン | あり | あり |
| 後付け | あり | 完全先付けの店もある |
| 切り上げ満貫 | **なし** | ありの店が多い |
| ダブロン | あり | 頭ハネの店もある |
| 途中流局 | 全てあり | 九種九牌のみの店もある |
| 順位点 | 段位ptで決まる（`majsoul.md`） | ウマ・オカ・トップ賞 |
| 判断への影響 | **ラス回避が最重要** | **トップ狙いの価値が上がる** |

トップ賞がある場では「1着を取りにいく」価値が上がる。
オーラスの押し引きが変わるので、リアルの相談では先に確認する。
