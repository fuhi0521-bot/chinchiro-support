# 牌効率

## 5ブロック理論 — すべての出発点

和了形は **4面子 + 1雀頭 = 5ブロック**。
手牌を見たらまず「ブロックが足りているか、多すぎるか」を数える。

- **ブロック過多**（6ブロック以上） → いちばん弱いターツを外す
- **ブロック不足**（4ブロック以下） → 孤立牌を残して育てる
- **ちょうど5ブロック** → ブロック内の質を上げる（悪形を良形に）

これを飛ばして「どの牌が浮いているか」から考えると、たいてい間違える。

## ターツ（未完成ブロック）の序列

強い順。**外すときは下から**。

1. **両面** `45m` → 3m6m（8枚）
2. **好形カンチャン** `35m`（3〜7絡み）→ 4m（4枚）だが両面に化けやすい
3. **シャンポン** `44m 55m` → 4m5m（4枚）だが打点が付きやすい
4. **端カンチャン** `13m` → 2m（4枚）。化けにくい
5. **ペンチャン** `12m` → 3m（4枚）。化けない。最弱

雀頭がない場合は、対子を1つ残す判断が上に割り込む。

## 孤立牌を残す価値

**3〜7の数牌 ＞ 2・8 ＞ 1・9 ＞ 客風 ＞ 三元牌・自風場風**

- `5m` は 3m4m6m7m の4種から両面ができる（最強の孤立牌）
- `2m` は 3m4m から。`1m` は 2m3m から（ペンチャンにしかならない側が半分）
- ただし **役牌は1枚重なれば1ブロック＋確定役** なので、
  手が遅い・安いときは先に切らない

## 見落としやすい形

| 形 | 待ち | 枚数 |
|---|---|---|
| **三面張** `34567m` | 2m 5m 8m | 12枚 |
| **のべたん** `4567m` | 4m 7m（単騎扱い、平和なし） | 6枚 |
| **中ぶくれ** `3455m` → `345m + 5m` | 5m が雀頭候補として優秀 | |
| **亜両面** `4456m` の 4m 切り or 6m 切り | 打点と受け入れで変わる | |
| **多門張** `2234567m` | 1m 2m 5m 8m など | 数えないと分からない |
| **一盃口含み** `223344m` | 面子2つ + 一盃口 | |

**迷ったら受け入れ枚数を数える。数えれば答えは出る。**
`mj.py discard` は全部の切り方を受け入れ順に並べてくれる。

## 一向聴の質を必ず区別する

同じ「1シャンテン」でも押し引きの結論が正反対になる。

| 形 | 例 | 評価 |
|---|---|---|
| **完全1シャンテン** | 両面 + 両面 + 雀頭 | 最強。押せる |
| **好形1シャンテン** | 両面2つ | 押せる |
| **良形+悪形** | 両面 + カンチャン | 五分 |
| **悪形2つ** | カンチャン + ペンチャン | 引く |
| **頭なし1シャンテン** | 面子3つ + ターツ1 | 実質もう1段遠い |

「1シャンテンだから押す」は雑すぎる。**中身を言う**。

## 打点との折り合い

受け入れを少し狭めてでも取りに行く価値があるもの:

- **タンヤオ** — 么九牌を1つ外すだけで付く。ほぼ常に得
- **平和** — 両面を残す方向と一致するので自然に付く
- **ドラ・赤** — 1枚で打点が1段上がる。孤立ドラは長く持つ

狙わないもの:

- **三色・一通** — 受け入れが狭くなりすぎる。「見えたら拾う」程度
- **チャンタ・純チャン** — 論外に狭い
- **七対子** — 対子4つ以上 **かつ** ドラ2以上、または字牌単騎で待てる形のときだけ

## 定型の判断

### 序盤（1〜6巡目）

- ブロック数を数えて、足りなければ **中張牌の孤立牌を残す**
- 役牌は1枚なら **6巡目くらいまでは持つ**（重なれば1ブロック＋役）
- 么九牌の孤立は早めに処理。ただし安全牌としての価値は残る

### 中盤（7〜11巡目）

- ブロックが揃ったら **悪形を良形に入れ替える**
- 他家の動きを見る。2副露が出たら押し引きモードに切り替える
- 安全牌を1〜2枚キープし始める（特に字牌）

### 終盤（12巡目〜）

- **アガリに向かうか、降りるか**をはっきり決める
- 形式テンパイは「安全に取れるなら」取る。危険牌を切ってまでは取らない
- 自分がテンパイなら押す、ノーテンなら降りる、が基本線

## よくある間違い

1. **ブロックを数えていない** — 6ブロックあるのに全部残そうとして手が進まない
2. **ペンチャンを大事にする** — `12m` は最弱。孤立の `5p` より価値が低いことが多い
3. **役牌を早く切る** — 1枚切りは中盤まで待つ。重なれば1ブロック＋確定役
4. **三色に寄りすぎる** — 受け入れを半分にして三色を狙うのはほぼ損
5. **雀頭を軽視する** — 頭なし1シャンテンは実質2シャンテン
6. **三面張を見落とす** — `34567m` を「45m + 67m」と見て片方を切る

## エンジンの使い方

```bash
S=skills/mahjong/scripts/mj.py
python3 $S discard 3456778m234p55s99s --top 5       # 何切る
python3 $S discard 3456778m234p55s99s --visible "111z999p"   # 場に見えている牌を考慮
python3 $S wait 34567m123p456p11s                    # 待ちの確認
python3 $S shanten 258m258p258s1234z                 # 一般形/七対子/国士 それぞれ
```

出力の読み方: `打7m テンパイ 2種4枚` は「7mを切るとテンパイ、待ちは2種類で残り4枚」。
**枚数だけで決めない**。打点・危険度・着順を足して結論を出す。
