# リーチ判断

## 原則: 先制テンパイはリーチ

**良形でも悪形でもリーチしたほうが得なことが多い。**
リーチは3つの利益を同時に生む。

1. **打点** — リーチ1翻 + 一発 + 裏ドラ + ツモ。平均で約2翻分上がる
2. **アガリ率** — 手変わりを待つより即座に待ちを固定したほうがアガれる
3. **他家の手止め** — 相手が降りる。放銃されにくくなるうえ、他家のアガリも減る

3つ目は数字に出にくいが大きい。**「悪形だからダマ」はたいてい損をしている。**

## ダマにするのは次の3つだけ

1. **ダマのままで満貫以上ある**
   リーチしても打点が大して上がらず、相手を降ろすデメリットのほうが大きい
2. **着順的に形式テンパイで足りる**
   オーラスで条件を満たしている、リーチ棒を出すと条件が変わる、など
3. **明確な危険牌待ちで、しかも打点が安い**
   1000点で無筋を待つなら、ダマで様子を見るか手変わりを待つ

それ以外は **迷ったらリーチ**と結論づける。

## 追っかけリーチ

先にリーチが入っている状態で、自分もテンパイした場合。

| 自分の形 | 判断 |
|---|---|
| 良形・打点あり | **追っかける** |
| 良形・安手 | 追っかける（微差だが押し寄り） |
| 悪形・満貫級 | 追っかける |
| 悪形・安手 | **降りる**（ダマにする意味も薄い） |
| 悪形・現物待ち | ダマで受ける（放銃しない待ちなら価値がある） |

追っかけの判断は **押し引きの基準表と同じ**。
「テンパイして押すと決めた」＝「リーチしてよい」とほぼ同義。
押すと決めたのにダマにするのは中途半端。

## 曲げるタイミング

### 早いリーチ（1〜6巡目）

- ほぼ常にリーチ。残り巡数が多いのでアガリ率が高い
- 悪形でも手変わりを待たずに曲げる。手変わりを待つ間に他家に先制される

### 中盤（7〜11巡目）

- 基本リーチ。ここが判断の中心
- 明確な手変わり（悪形→良形が4枚以上の受け入れで見える）があるなら1〜2巡待つ余地

### 終盤（12巡目以降）

- **アガリ率が落ちる**ので、リーチの価値も落ちる
- ただし他家を降ろす効果は残る。自分がラス目なら曲げる価値がある
- 15巡目以降の悪形リーチはほぼ利益がない。形式テンパイに寄せる

## 宣言牌の選び方

リーチ宣言牌は **相手に最も情報を与える1枚**であり、**最も危険な1枚**でもある。

- 同じテンパイになるなら、**より安全な牌**を宣言牌にする
- 宣言牌の周辺は「使っていない」と読まれる。それを利用した引っかけもあるが、
  引っかけを狙って待ちを悪くするのは損
- **現物や通っている牌が宣言牌にできるなら理想**

## リーチ後にできること・できないこと

| 行為 | 可否 |
|---|---|
| ツモ切り | ○（それしかできない） |
| ロン・ツモ | ○ |
| 暗槓 | △ 待ちと面子構成が変わらない場合のみ |
| 明槓・ポン・チー | × |
| 手替え | × |
| 見逃し | ○ だがフリテンになりその局ロン不可 |

**リーチ後のフリテン**が最大の事故。三面待ちの1つを自分で切っていないか、
リーチ前に必ず確認する。

## リーチ棒のコスト

リーチは **1000点の投資**。以下では割に合わない場合がある。

- **点数が1000点ちょうど**（リーチすると0点で終了 → そもそもリーチできない）
- **オーラスでトップ目、点差が僅差** — リーチ棒で捲られる可能性
- **ラス目で1000点差** — リーチ棒を出すと3着に上がる条件が変わる

オーラスは **リーチ棒を出した後の点差** で条件を計算する。

## 数字の目安

- 先制リーチのアガリ率は **およそ50%**（良形ならもう少し高い、悪形なら40%前後）
- 放銃率は **およそ15%**
- リーチの平均打点は **リーチのみでも約5000点**（一発・裏・ツモ込み）
- **リーチのみ**でも期待値はプラス。「安いからやめる」は誤り
