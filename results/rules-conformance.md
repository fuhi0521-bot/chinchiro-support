### ノーテン罰符の検証について

「収支の合計が0」だけでは不十分（全員±0でも通ってしまう）ので、
**テンパイ人数ごとに金額そのものを照合**している。

| テンパイ者 | テンパイ1人あたり | ノーテン1人あたり | 600局中の出現 |
|---|---|---|---|
| 0人 | 0 | 0 | 4回 |
| 1人 | +3000 | −1000 | 85回 |
| 2人 | +1500 | −1500 | 61回 |
| 3人 | +1000 | −3000 | 7回 |
| 4人 | 0 | 0 | 0回 |

157回の流局すべてで金額が一致した。テンパイ判定もエンジンとは独立に数え直して照合している。

なお **テンパイ3人・4人の流局が極端に少ない**（7回 / 0回）のはルールの問題ではなく、
AIの流局時テンパイ率が実戦より低いため（`results/match-final.md` 参照）。
ルールの処理は正しいが、AIの速度が人間に届いていない。

## 実装していないもの（既知の差）

| 項目 | 影響 |
|---|---|
| **責任払い（包）** — 大三元・大四喜 | 役満が絡む極めて稀な場面のみ |
| **流し満貫** | 出現率が非常に低い |
| **天和・地和** | Contextに口はあるが、対局側から発火させていない（出現率0.03%程度） |
| **人和** | 雀魂も採用していないので影響なし |
| **大明槓の嶺上開花** | 大明槓の嶺上牌でツモ和了を判定していない（暗槓・加槓は判定する） |
| **スジ喰い替え** | 現物のみ禁止。雀魂がスジも禁止しているかは未確認 |
| **明槓のドラめくりのタイミング** | 即めくりにしている。雀魂は打牌後の可能性がある |

いずれも**出現率が低く、順位統計にはほぼ影響しない**が、
「完全に雀魂と同じ」ではないので明示しておく。

## 途中で見つけて直したバグ

この照合作業で3件見つかった。すべて修正済みで、再発防止のテストを入れてある。

### 1. 王牌のインデックスがずれていた

嶺上牌を `dead.pop()` で末尾から取り、`dead.insert(0, ...)` で先頭に補充していたため、
**カンのたびに王牌全体が1つずれていた**。結果:

- カンドラが本来とは別の牌（元の裏ドラ表示牌）を指していた
- **カン裏（裏ドラの2枚目以降）が一度も追加されていなかった**

王牌14枚の役割を固定位置にして修正。ドラ表示は index 0,2,4,6,8、
裏ドラはその1つ下、嶺上牌は 13,12,11,10。位置が衝突しないことを検査している。

### 2. 一発が消えなかった

一発は鳴きが入ったときしかフラグを落としておらず、
**宣言後に何巡経っても一発が付き続けていた**。リーチ手の打点が過大になっていた。

「宣言の次の自分の打牌で切れる」ように修正。修正後のリーチ和了に占める一発は16.4%。

### 3. ロン時の本場が二重に加算されていた

`payment.ron` には既に本場（1本300点）が入っているのに、
`settle_ron` でもう一度足していた。点棒の保存則では気づけない種類のバグ
（放銃者と和了者の双方に同じ額を足し引きしていたため）。

### 4. 現物喰い替えができていた

鳴いた直後の打牌に制限をかけていなかった。250局中2件発生していた。
`Player.discard` に禁止牌を渡す形にして修正。

## 影響の見積り

| バグ | 発生頻度 | 過去の結果への影響 |
|---|---|---|
| 王牌のずれ | カンが入る局のみ（200局中15局） | 小。カンドラ・カン裏が絡む和了の打点 |
| 一発が消えない | リーチ全部 | **中。リーチ手の打点が過大だった** |
| 本場の二重加算 | ロン全部（本場がある局） | 小。1本につき300点 |
| 現物喰い替え | 250局中2件 | ごく小 |

**一発のバグはこれまでの実験結果すべてに影響していた。**
リーチ手の価値が過大に出ていたので、「攻撃型が強い」という結論が
このバグに助けられていた可能性を疑い、修正後のエンジンで4人の対戦をやり直した。

結果、**順位の序列は変わらなかった**（`results/match-final.md`）。
一方で平均和了打点は 6899〜7231 → 6169〜6623 に下がり、
実戦の目安（6000〜6500）にちょうど収まった。バグ修正で較正が改善している。
