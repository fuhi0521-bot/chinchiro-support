# 6人打ち 3000半荘（各自2000半荘・34,525局）

```
python3 skills/mahjong/scripts/mj.py match --hanchan 3000 --seed 61803 -j 4 --lineup six --awareness allast
```

麻雀は4人でしか打てないので、6人だと毎半荘2人が抜け番。
6半荘で全員が各席1回ずつ座り、抜け番も同数になるローテーションにしてある。

## なぜ負けたのか — 和了率が順位のほぼ全て

| 雀士 | 和了率 | 放銃率 | 流局時テンパイ | 平均順位 |
|---|---|---|---|---|
| ゆうだい | **20.01%** | **11.63%** | 50.3% | 2.389 |
| かなめ | 19.62% | 10.97% | 49.1% | 2.456 |
| きくちゃん | 19.40% | 10.19% | 44.9% | 2.450 |
| なおき | 18.10% | 9.90% | 39.5% | 2.506 |
| さとる | 17.89% | **9.22%** | 39.3% | 2.479 |
| ゆみこ | **14.41%** | **8.36%** | 28.0% | 2.720 |

平均順位との相関:

| 指標 | 相関 |
|---|---|
| **和了率** | **−0.976** |
| 流局時テンパイ率 | −0.939 |
| 放銃率 | **−0.857**（符号が逆） |

**放銃率が高いほど順位が良い。** 守備指標としては符号が逆になっている。
攻める打ち手は和了も放銃も増えるが、和了のほうが効くため。

和了率だけで回帰すると:

```
平均順位 = 3.491 − 0.0543 × 和了率(%)      R² = 0.953
```

**和了率だけで順位の95%が説明できる。** 残差はどれも±0.04以内で、
読み・危険度・オーラス条件といった上物は、順位にほとんど寄与していない。

### この数字の意味

**和了率1ptは平均順位0.054に相当する。**

このプロジェクトで測ってきた効果の大きさと比べると:

| 施策 | 平均順位への効果 |
|---|---|
| 和了率を1pt上げる | **−0.054** |
| 押し引きの閾値を下げる（読みと組み合わせ） | −0.089 |
| オーラスの条件計算 | 検出できず（<0.05） |
| 染め手を選択的に狙う | 検出できず |
| 読みの精度を上げる（閾値そのまま） | **+0.10（悪化）** |

そして このAIの和了率は実戦より **約3pt低い**（流局率 25.6% vs 実戦16.0%）。
**そこを埋めれば −0.16。これまで測ったどの施策より大きい。**

## 結論

守備・読み・状況判断の作り込みは、**この環境では順位に効いていない**。
効くのは速度（和了率）だけ。

ただし重要な留保がある。**この結論はボット集団の性質かもしれない。**
全員が実戦より遅い（流局率25.6%）ので、本物の脅威が少なく、
守備の出番が構造的に少ない。人間の上級者どうしなら守備の価値は上がるはず。

## 次にやるべきこと

1. **先読み探索**（2〜3手先の受け入れを見る）— 和了率の最大の伸びしろ。実装は重い
2. **良形・平和への寄せ** — 平和が実戦より6.0pt低い。実装は打牌スコアの調整だけで軽い
3. **待ち取り** — 同じシャンテンで複数のテンパイが選べるときの選択が無い

守備側（読み・危険度）は、上の3つを片付けてから戻ってくるべき。
