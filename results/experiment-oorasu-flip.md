# オーラス限定実験: 2SEの結果が、24倍のデータで符号ごと反転した

## 何を測ろうとしたか

`_situational_riichi`（オーラスの着順条件）が、ダマ判定に壊れた推定値を
使っていた。役なしの手にも 1300〜7800点を返す関数で、

```python
if dama_value >= need and width >= 3:
    return False   # 「ダマの出アガリで条件を満たせる」のでリーチしない
```

を判断していた。`need` は**ロンで条件を満たすのに必要な打点**なので、
役がなければこの比較は成立しない。`dama_ron_value`（役判定を通す）に
差し替えた。その是非を測る。

オーラスは半荘だと11局に1局しか来ない。そこで薄まらないよう、
**オーラスの局面だけを並べる**実験にした（`mj/oorasu_lab.py`）。
同じ局に旧2人・新2人を座らせるので順位が完全にペア化され、
局ごとの手牌のばらつきが打ち消えて標準誤差が小さくなる。

## 結果

| 規模 | 旧（推定） | 新（役判定） | 1人あたりの差 | |
|---|---|---|---|---|
| 500局 | 2.5590 | 2.4410 | **新が 0.118 良い** | 2.1SE |
| **12000局** | **2.4862** | **2.5138** | **旧が 0.028 良い** | **2.3SE** |

**符号が反転した。** しかも両方とも「2SE前後」だった。

判定がひっくり返ったリーチ判断は 13.0%（500局時点の計測）なので、
両者は確かに違う打ち方をしている。差が無いのではなく、
**どちらが良いかを順位では決められない**。

## 今日3回目の同じ失敗

| 実験 | 予備の結果 | 本番の結果 |
|---|---|---|
| 守備の許容幅（4000→6000半荘） | −0.028（2.5SE） | 消えた |
| ダマ判定（6000半荘） | — | +0.002（0.26SE） |
| **オーラス（500→12000局）** | **+0.118（2.1SE）** | **−0.028（2.3SE・符号反転）** |

**2〜2.5SE は、この題材では信用できない。** 3回とも裏切られた。
理由は分散が大きいから。麻雀1局の着順は手牌のばらつきに支配され、
打ち方の差はその上に乗る薄い層でしかない。

必要な局数（このオーラス実験の実測 SE=0.0118／12000局 から換算）:

| 検出したい差 | 必要な局数 | 所要時間 |
|---|---|---|
| 0.028 を 3SE で | 約 78,000 | 約4.5時間 |
| 0.010 を 3SE で | 約 610,000 | 約36時間 |

## だから採否は順位で決めない

順位で決着がつかない以上、**規則として白黒がつくもの**で決める。

役がなければダマではロンできない。これは好みではなく麻雀の規則。
だから「ダマの出アガリで着順条件を満たせる」と判断した場面のうち、
**手に役が無かった回数**は、そのまま旧ロジックの誤りの回数になる。
これは率の直接カウントなので、標準誤差の話が要らない。

順位の測定は「悪化していないか」の確認にとどめる。
今回の 0.028（2.3SE）はその確認としても弱いので、
**悪化したとも改善したとも言えない**が正しい報告になる。

## 規則で数えたら、一発で決着した

オーラス3000局を回し、旧ロジックが着順条件を見て判断した
リーチ判断 5726回のうち、「ダマで足りる」としてリーチを
見送った場面を数えた。

| | 回数 |
|---|---|
| 旧が「ダマで足りる」としてリーチを見送った | 3725 |
| **うち、手に役が無くロンできなかった** | **1733（46.5%）** |

**見送りの半分近くが、規則上ありえない判断だった。**
役がなければダマではロンできない。「ダマの出アガリで条件を満たす」
と判断しておきながら、その出アガリ自体が不可能だった。

順位では 12000局・42分かけても符号すら定まらなかったのに、
規則で数えたら 3000局で 46.5% という動かない数字が出た。
**新ロジックを採用する。理由は順位ではなく、旧が規則に反していたから。**

## この実験自体の設計は良かった

オーラスだけを並べ、同じ局に2人ずつ座らせる設計は、
半荘を回すより効率が良い（順位が完全にペア化されるため）。
12000局・42分で SE=0.0118。同じ精度を半荘で得るには
はるかに長くかかる。**測り方の改善は本物だった。**
測っている対象が、順位という粗い物差しでは掴めないだけ。
