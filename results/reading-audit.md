# 河読みの精度を部品ごとに測る

河読みは **別々の2つの部品** でできている。混ぜて語ると何が効いているか分からなくなる。

1. **テンパイ読み** — この人テンパイしているか（`reading.tenpai_probability`）
2. **当たり牌読み** — どの牌が当たるか（`reading.wait_risk`）

測り方: 対局を回し、打牌のたびに **相手の実際の手牌** と突き合わせる。
4シード × 150局、合計 127,624標本（当たり牌読み）。

## 1. テンパイ読み — 今回は触っていない

AUC **0.897**（4シード: 0.894 / 0.912 / 0.880 / 0.903）。

13.4万局面で作った実測表（副露数 × 巡目 × 直近3打のツモ切り数）のままで、
今回のセッションでは一切変更していない。

較正も合っている（予測30-50%の帯で実測51%など）。

## 2. 当たり牌読み — 上がった

部品を1つずつ外して、同じ局面で比べた。差がその部品の貢献。

| 条件 | AUC | 現行との差 | 4シードのばらつき |
|---|---|---|---|
| **現行（全部入り）** | **0.6570** | — | 0.630〜0.687 |
| 早切りの周辺を見ない | 0.6323 | **−0.0247** | −0.010〜−0.040 |
| スジを見ない | 0.6426 | **−0.0144** | −0.011〜−0.019 |
| 枚数を見ない ← 今回追加 | 0.6517 | −0.0053 | **+0.001〜−0.010** |
| 通った牌を見ない ← 今回追加 | 0.6549 | −0.0022 | −0.0017〜−0.0027 |
| 牌の位置だけ | 0.5893 | −0.0678 | −0.039〜−0.083 |

今回足した2つの寄与は合わせて **+0.0075**。
モデル全体の強み（+0.0678）の約1割にあたる。

### 前回の報告の訂正

セッション中に「枚数を見る効果は AUC 0.6347 → 0.6521（+0.017）」と報告したが、
これは **1シードだけの値**。4シードで測り直すと **+0.005** で、
しかも1シードでは符号が反転している（+0.001）。

平均 +0.0053 / SE 0.0024 なので効果自体は残るが、**+0.017 は過大だった**。

### 「リーチ後に通った牌」の効きが小さい理由

ルール上は完全な安全牌なのに、AUC への寄与は +0.0022 しかない。
ただし4シードすべてで −0.0017〜−0.0027 と、ばらつきがほぼゼロ。**小さいが確実**。

小さいのは、通った牌の多くが「枚数を見る」係数と重複して拾われているため
（通った牌は誰かの河にある＝場に切れている牌でもある）。
AUC は順位付けの指標なので、同じ牌を2つの理由で安全と判定しても加算されない。

**実戦では話が別。** 人間は「切れている枚数」を数えるより
「リーチ後に通ったか」を思い出すほうが速くて確実なので、こちらを優先していい。

## 3. 精度が上がっても放銃率は下がっていない

かなめの放銃率:

| | 放銃率 |
|---|---|
| 今回の変更前（10000半荘） | 11.77% |
| 変更後 1本目 | 11.83% |
| 変更後 2本目 | 11.57% |

**ほぼ動いていない。** これは失敗ではなく、以前からの結論どおり。

> 読みで分かることは2つあって、価値が違う。
> 「テンパイしている」→ 降りる。これは誰でもやる。
> **「テンパイしていない」→ 自信を持って押す。こちらが本体。**

かなめは `safety_weight=0.5` と低く、読みの結果を **押す方向** に使う設計になっている。
だから読みが良くなっても放銃率は下がらず、和了率と流局時テンパイ率のほうに出る
（かなめの流局時テンパイ率 51.7% は6人中最高）。

## 打ち手にとっての優先順位

AUC の寄与順に並べると、覚える価値の順になる。

1. **序盤の手出しの周辺**（+0.025）— いちばん効く。しかも見落とされやすい
2. **スジ**（+0.014）— 基本。ただし単独では思ったほど強くない
3. **場に切れている枚数**（+0.005）— 3枚切れの無筋はスジより安全
4. **リーチ後に通った牌**（+0.002）— 効きは小さいが確実。数えるのが速い

再現:

```bash
python3 skills/mahjong/scripts/mj/risk_fit.py --games 150 --seed 101
```
