# 実験: ダマ判定を推定から役判定に変える（6000半荘）→ 順位は動かなかった

## 直したもの

リーチ／ダマの分岐は、ダマのままの打点を `damaten_value` と比べていた。
その打点は `estimate_value(dama=True)` — ドラ・役牌・タンヤオを数えるだけで
**役が成立するかを一度も見ず**、最後に `max(1, han)` で必ず1翻以上に切り上げる。

600局・リーチ判断665回を計測した結果:

| | 回数 |
|---|---|
| **ダマではロンできない手**（役なし／待ち枯れ） | **297回 = 44.7%** |

その297回に旧ロジックが付けていた「ダマ打点」:

```
1300点 141回 / 1950点 67回 / 2600点 42回
3900点  19回 / 5200点 14回 / 7700〜7800点 14回
```

ロンで1点も取れない手を、最大7800点と見積もっていた。

判定がひっくり返る割合:

| damaten_value | 3900 | 5200 | 8000 | 12000 |
|---|---|---|---|---|
| 判定が変わる | 25.0% | 21.4% | 12.8% | 5.4% |

直し: `dama_ron_value()` を追加。テンパイ形の各待ちを `yaku.evaluate()` に
通し、役が成立しなければ 0点。4枚とも見えている待ちは出てこないので数えない。

## 6000半荘（同型2人ずつ・damaten_value=5200）

| | 平均順位 |
|---|---|
| 旧A（推定） | 2.508 |
| 旧B（推定） | 2.490 |
| 新A（役判定） | 2.503 |
| 新B（役判定） | 2.499 |

| | 平均順位 | 同型2人の差 |
|---|---|---|
| 旧（2人平均） | **2.499** | 0.018 |
| 新（2人平均） | **2.501** | 0.004 |

**差 +0.002。この実験の標準誤差は約0.008 なので 0.26SE。完全に誤差の中。**

| | 旧 | 新 | 差 |
|---|---|---|---|
| 立直率 | 20.55% | 20.04% | **−0.51pt** |
| 和了率 | 20.09% | 20.27% | +0.18pt |
| 放銃率 | 11.87% | 11.91% | +0.04pt |

## 立直率が下がったのは、予想と逆

「役なしを0点にする」なら、ダマの打点が下がってリーチが**増える**はずだった。
実際は減った。理由は、この直しが2方向に効いているから。

- **役なしの手**: 1300点 → 0点 … ダマの条件を満たさなくなり、リーチが増える
- **役ありの手**: 粗い推定 → 実際のロン点数 … 符計算と本場が入るぶん
  推定より**高く出ることが多い**。ダマの条件を満たしやすくなり、リーチが減る

計測でも、damaten_value=5200 では旧「ダマで十分」104回 → 新176回 と増えていた。
差し引きで立直率は 0.51pt 下がった。

## 判定

**採用する。ただし「強くなったから」ではない。**

- 役なしの手はダマではロンできない。これは好みではなく麻雀の規則で、
  0点が正しい値。**正しさの問題であって、勝率の問題ではない**
- 順位への代償は測れなかった（0.26SE）
- `damaten_value` が言葉どおりの意味を持つようになったので、
  **これから閾値を掃引すれば、はじめて意味のある結果になる**

## 以前の結論の撤回

`results/experiment-damaten.md` の
「3900〜12000 のどこに置いても順位差0.04以内なので 12000 でよい」は、
**44.7%の場面で誤った量を測る関数の上で回した結果**だった。
つまみが効かなく見えたのは、つまみの先が壊れた計器につながっていたから。
現状維持の根拠にならない。掃引はやり直す。

## この実験から得た、もっと一般的な教訓

**平均順位では、この種の直しの是非を判定できない。**

同型2人が6000半荘で 0.018 離れる。2対2比較の標準誤差は約0.008。
3SEで検出するのに必要な半荘数:

| 効果 | 必要な半荘数 | 所要時間 |
|---|---|---|
| 0.030 | 6,000 | 約1時間 |
| 0.010 | 約45,000 | 約7時間 |
| 0.005 | 約170,000 | 1日以上 |

本物の改善はたいてい 0.01 未満で、**測れる範囲の外**にある。
だから採否の基準は順位ではなく、次の順で置く。

1. **不変条件**（局数ゼロ）… 「役なしなのにダマ打点7800点」は測るまでもなく誤り
2. **決定単位の監査**（600局）… 打牌の性質を直接数える。率なのでノイズが無い
3. **半荘の積み上げ** … 「悪化していないか」の確認だけ。発見の道具にしない
