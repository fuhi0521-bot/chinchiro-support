# 実験: ダマの基準を、バグを直した意味で測り直す（6000半荘）

## 直したバグ

ダマ判断は長らく **リーチ込みの打点** を「リーチしない基準」と比べていた。

```python
value = self.estimate_value(view)          # ← リーチ・一発・裏ドラの +2翻 を含む
if value - 1000 >= st.damaten_value and width <= 4:
    return False                            # ダマにする
```

`estimate_value(view)` は門前のとき「リーチ + ツモ/一発/裏」の期待上乗せとして
+2翻を足す。つまり **リーチしたときの打点** で「リーチしない判断」をしていた。

400局を計測した結果:

| | ダマ率 | 中身 |
|---|---|---|
| ゆみこ（`damaten_value=5200`）修正前 | **48.6%** | 「打点十分」でダマにした手のダマ打点が **1950点**（25回）・2600点（14回）・3900点（15回） |
| ゆみこ 修正後 | **7.9%** | 5200点（3回）・7800点（1回）。1950点の1件は「終盤・悪形・安手」の別ルール |

**1950点の手を「5200点の基準を超えている」と判定してダマにしていた。**

かなめは修正前後とも **100%リーチ**（90/90）。`damaten_value=12000` だと
「ダマ12000点かつ悪形」がまず起きないので、正しく計算し直しても変わらない。

修正:

```python
if self.estimate_value(view, dama=True) >= st.damaten_value and width <= 4:
    return False
```

## 測り直し

`damaten_value` の意味が変わったので、6000半荘で取り直した。
土台はかなめ（`value_weight=1.4` / `deep_shape=True`）。標準誤差は約 0.024。

| | 平均順位 | 即リーとの差 | 和了率 | 立直率 | 平均和了 |
|---|---|---|---|---|---|
| ダマ5200 | **2.479** | −0.005 | 20.35% | 20.43% | 6011 |
| 即リー（12000） | 2.484 | — | 20.19% | 21.56% | 6078 |
| ダマ8000 | 2.514 | +0.030 | 20.13% | 21.52% | 6060 |
| ダマ3900 | 2.523 | +0.039 | 19.86% | 19.66% | 5927 |

**ダマの基準を動かしても順位に差は出なかった。**

- 1位（ダマ5200）と2位（即リー）の差 0.005 は標準誤差の1/5
- 並びが単調でない（5200 が最良なのに 8000 が 12000 より悪い）。
  **これは差が無いときの典型的な形**

つまり、**かなめは `damaten_value=12000`（＝事実上つねに即リー）のままでよい。**
以前 6000半荘で「即リー（8000→12000）が最良（−0.029）」と出たのは、
**バグった分岐を無効化していただけ**だった可能性が高い。
直したいま、その効果は再現しない。

## 実戦への移し方

**「ダマにするかどうか」で悩む価値は、思ったより小さい。**
このシミュレータの範囲では、ダマの基準を 3900〜12000 のどこに置いても
平均順位は 0.04 の幅に収まっている。

`references/riichi.md` が書いているとおり、ダマにする理由は3つだけ
（オーラスで条件を満たしている / 役満が見える / 手変わりが明確）で、
**それ以外は曲げてよい**。打点計算に自信がないなら、なおさら即リーが安全。

そして今回の教訓のほうが大事かもしれない。

> **「ダマで十分高いか」を判断するときは、ダマの打点で比べること。**
> リーチ込みの打点で比べると、1950点の手が「十分高い」に見える。

人間も同じ間違いをする。「リーチしたら満貫だからダマでいいや」は逆で、
ダマなら1300点にしかならないなら曲げるべき。
