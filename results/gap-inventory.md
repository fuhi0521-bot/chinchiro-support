# 足りないものの洗い出し（現状と優先順）

ゴールは **打ち手（人間）が強くなること**。エージェントとシミュレーションは
そのための知識を作る道具。だから優先順位は「エージェントの順位が上がるか」ではなく
**「実戦で使える知識が増えるか」** で付けている。

最終更新: 最終10000半荘×2本を終えた時点（かなめ1位、p=0.040）。

## B. まだ足りないもの（優先順）

### 1. 深い先読み — 3手先まで

いまは1シャンテンで「2段目の受け入れ」までしか見ていない
（しかも上位4候補×受け入れ6種に絞ってある）。
2シャンテンはブロックの質で近似したが、**本当の3手先は見ていない**。

- 効きそうな場面: 配牌〜5巡目の「どのブロックを残すか」
- 難しさ: 計算量。1手増えるごとに約34倍
- 現実的な形: 完全な探索ではなく「良形変化の枚数」を数える
  （例: `4556m` の 3m/6m 引きで両面が2つになる、を先に数えておく）

**実戦への効きは大きい。** 序盤の何切るで一番差が付くのはここ。

### 2. 【済】山読みを守備側に使う → 実装して効果を確認した

`wait_risk` に「その牌が場に何枚切れているか」を入れた。
同一局面での AUC が 0.6347 → 0.6521。
あわせて「リーチ後に通った牌は現物」の実装漏れも直した。

**攻撃側（自分の受け入れ・待ちを山の枚数で数える）は測ったら損だった。**
山に濃い牌は誰も持っていない牌なので、待っても出てこない。
`results/experiment-wall.md` に詳細。

### 2b. 山読みの「正しい」使い方はまだ実装していない

「山に何枚あるか（ツモ）」と「出やすいか（ロン）」を足して比べる形。
片方だけを最大化したのが上の失敗。両方を推定して足す実装は未着手で、
ここが山読みの本命。

### 3. 役満・大物手

8万和了で **役満0**。四暗刻・大三元・国士は「向かう」判断が入っていない。

- 順位への影響: **ほぼ無い**（頻度 0.03% 程度）
- 知識としての価値: あり。「国士に向かうべき配牌」は実戦で年に数回来る
- 対々和は実装したので、四暗刻はその延長で入れられる

優先度は低いが、**知識ベースとしての穴**なので埋めたい。

### 4. 牌譜の読み込み

いまは自分のAIの対局しか分析できない。
**雀魂の牌譜を読み込めれば、打ち手自身の局を診断できる**。

- これがゴールに一番近い機能。「私の何切るミス一覧」が出せる
- 難しさ: 牌譜フォーマット（雀魂は非公開・天鳳は公開）
- 現実的な形: 手打ちで局面を入力して診断する CLI はすでにある
  （`mj.py discard` / `danger` / `oorasu`）。まずはそれを使う運用を固めるほうが早い

### 5. 三人麻雀

雀魂の三麻は牌種も打ち方も別ゲーム（萬子の2〜8が無い、抜きドラ、ツモ損）。
**四麻の知識はそのままでは使えない**。打ち手が三麻を打つなら別途必要。

現状: **未着手**。四麻に集中するなら要らない。

### 6. 副露読み（待ちの特定）

テンパイの察知はできているが、**待ちの特定**はほとんどできていない。
副露の中身から待ちを絞る読みを測ったら、
1色に寄った鳴きでもテンパイ時の待ちの76〜80%は他の色だった。

つまり **副露の色から待ちを読むのは、思ったほど効かない**。
これは実装の穴ではなく **「効かないと分かった」** 項目。

### 7. 【済】打ち手向けの練習機能 → `mj.py drill`

実際の対局から局面を拾って出題する。答えは別コマンド。

  discard 牌効率 / danger 押し引き / tenpai 河読み / wall 山読み

`danger` と `tenpai` の答えには **相手の実際の待ち・シャンテン** が出る。
実戦では答え合わせできない部分なので、ここでしか練習できない。

### 7b. まだ無いもの: 出題の難度調整と成績の記録

いまは毎回ランダムに出るだけ。間違えた種類を覚えて出し直す、
正答率を記録する、といった仕組みは無い。

## C. 測って「要らない」と分かったもの

作らない理由がはっきりしているもの。同じ道を二度通らないために残す。

| 項目 | 測った結果 |
|---|---|
| 河の色の偏りから染めを読む | 入れないほうが当たった（判別 68.5% → 69.9%） |
| またぎスジ | AUC が上がらなかった |
| 鳴いた後の危険度補正 | 手出し／ツモ切りの情報と重複 |
| 実戦の副露率（32.6%）に合わせる | 順位が落ちた。**統計に合わせる ≠ 強い** |
| 点数状況で打ち回しを変える（オーラス以外） | 9000半荘で差が出なかった |
| 読みの精度だけを上げる | **読まないより弱くなった**（押しを強めないと損） |
| 受け入れ・待ちを「山に残っている枚数」で数える | 和了率 −0.33pt。山に濃い牌は出てこない |
| 押すときも安全牌を1枚残す | 和了率 −0.33pt かつ放銃率 +0.19pt で両方悪化 |
