# AI雀士 4人

`skills/mahjong/scripts/mj/players.py` に実装した、性格の違う4人の打ち手。
判断ロジックは全員共通で、**違いはパラメータだけ**。方針の差だけで強さを比べられる。

判断は `skills/mahjong/references/` の基準をそのまま数値化してある
（押し引きは `push-fold.md` の基準表、危険度は `probability.md` の放銃率）。

## パラメータ

鳴きの基準は実戦の統計（副露率30〜35% / 平均和了6000〜6500点）に合わせて較正済み。
性格の差は **押し引き・打点の追い方・守備の重み・リーチ方針** で表してある。

| | ゆうだい | なおき | きくちゃん | ゆみこ |
|---|---|---|---|---|
| 性格 | 攻撃型 | 教科書型 | 速攻・鳴き型 | 守備・ラス回避型 |
| 押し引きの閾値 | 0.32（緩い＝押す） | 0.50 | 0.45 | 0.64（厳しい＝降りる） |
| 鳴く最低打点 | 2000 | 2000 | **1000** | 3900 |
| 鳴ける最大シャンテン | 3 | 3 | 3 | 2 |
| ダマにする打点 | 12000以上 | 8000以上 | 8000以上 | 5200以上 |
| 悪形・安手でもリーチ | する | する | する | **しない** |
| 押すときの安全度重視 | 0.5（軽視） | 1.0 | 0.8 | **1.6（重視）** |
| 打点重視（受け入れを削るか） | **1.4** | 1.0 | 0.6（速度優先） | 1.0 |
| ラス目での押し増し | +0.20 | +0.15 | +0.15 | +0.10 |

### 較正について

最初の実装では4人の鳴きの基準がばらばらで、きくちゃん以外は絞りすぎていた
（副露率11%、平均和了8500点、飛び率42%）。実戦とかけ離れていたため、
全員を較正し直してある。詳細は `results/experiment-awareness.md`。

## 4人の狙い

- **ゆうだい** — 押し引きの閾値を下げ、打点を追う。リーチ率が高く放銃も多い。
  「攻撃は最大の防御」が本当に成立するかを見るための打ち手
- **なおき** — 基準表どおりに打つ。他の3人を評価するための物差し
- **きくちゃん** — 安手でも鳴いて速度を取る。副露率が突出する。
  「速さは順位になるか」を見る打ち手
- **ゆみこ** — 押し引きを厳しく、悪形安手はリーチしない。ラス回避に全振り。
  玉の間のポイント構造で本当に得なのかを検証する打ち手

## 点数状況による打ち回し

`--awareness` を付けると、4人全員に状況判断が乗る。

| 場面 | 判断 |
|---|---|
| オーラス・トップ目 | ダマ（アガれば終局。リーチ棒を出す理由がない） |
| オーラス・ダマで条件を満たす | ダマ（リーチすると他家が降りて出アガリが減る） |
| オーラス・ダマでは足りない | リーチ（一発・裏で条件に届く可能性を買う） |
| オーラス・ラス目・着順が上がらない和了 | 見逃し（アガるとラスが確定する） |
| オーラス終盤・上下と4000点差以内 | 形式テンパイを取りに行く |

条件計算は `mj/placement.py`。`mj.py oorasu` で人間も同じ計算を引ける。

**ただし、この打ち回しが順位を上げるという証拠は9000半荘の実験で得られていない。**
`results/experiment-awareness.md` を参照。

## 共通のロジック

1. **打牌** — シャンテンが最小になる牌のうち、受け入れ・打点・危険度の合計で選ぶ
2. **押し引き** — 相手の脅威度（リーチ=1.0 / 3副露=0.9 / 2副露=0.5）と自分の
   （シャンテン × 形の質 × 打点帯）から押し価値を出し、閾値と比べる。
   **閾値ちょうどは五分**なので、決定論ではなく確率で決める（基準表が「五分」と
   書いている行を、実際に五分の頻度で押す）
3. **降り** — 安全度が最優先。ただし**同じくらい安全なら手を残す**（回し打ち寄り）
4. **鳴き** — 鳴いた後の13枚でシャンテンが進むか、役に向かえるか、打点が閾値を
   超えるかで判断。鳴いた後は**その役に向かって打つ**（タンヤオなら么九牌から切る）

## 実装していないもの

- 高度な読み（手出し/ツモ切り、待ちの絞り込み）
- 先読み探索（次巡以降の受け入れを評価する）
- 対戦相手ごとのクセの学習

## 走らせる

```bash
# 4人の対戦
python3 skills/mahjong/scripts/mj.py match --hanchan 2000 -j 4
# 状況判断を載せて対戦
python3 skills/mahjong/scripts/mj.py match --hanchan 2000 -j 4 --awareness allast
# 状況判断の要素だけを比べる
python3 skills/mahjong/scripts/mj.py match --hanchan 2000 -j 4 --lineup awareness
```
